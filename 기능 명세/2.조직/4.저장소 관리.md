# 📝 2.4.1 저장소 등록

## 기능 목적

> 조직에서 사용할 저장소를 등록한다.

## 사용자 및 권한

- Organization Role : `ORG_OWNER`

## 사전 조건

- 조직 상태가 `ACTIVE`여야 한다.

## 입력값

| 항목 | 형식 | 필수 여부 | 설명            |
| --- | --- | :---: |---------------|
| 저장소명 | String | O | 조직 내 중복 불가    |
| 저장소 설명 | String | X | 저장소에 대한 상세 설명 |

## 처리 절차

1. 사용자 Role 확인한다.
2. 조직 상태를 확인한다.
3. 저장소를 생성한다.

## 업무 규칙

- `ORG_OWNER`만 등록할 수 있다.
- 조직 상태가 `ACTIVE`여야 한다.

## 처리 결과

- [ ] 저장소가 생성된다.

## 예외 처리

| 예외 조건 | 처리           |
| --- |--------------|
| `OWNER` 권한이 아님 | 권한 없음을 반환한다. |
| 조직 상태가 `ACTIVE`가 아님 | 등록을 거부한다.    |

# 📝 2.4.2 저장소 조회

## 기능 목적

> 조직의 저장소 정보를 조회한다.

## 사전 조건

- 조직에 소속되어 있어야 한다.

## 처리 절차

1. 조직 소속 여부를 확인한다.
2. 저장소 정보를 조회한다.
3. 조회 결과를 반환한다.

## 업무 규칙

- 조직 구성원만 조회할 수 있다.
- 저장소 목록 및 상세 정보를 조회할 수 있다.
- `ACTIVE` 상태인  저장소만 조회한다.

## 처리 결과

- 저장소 목록 또는 상세 정보를 반환한다.

## 예외 처리

| 예외 조건 | 처리                  |
| --- |---------------------|
| 조직 구성원이 아님 | 권한 없음을 반환한다.     |
| 존재하지 않는 저장소 | 존재하지 않는 저장소임을 반환한다. |

# 📝 2.4.3 저장소 수정

## 기능 목적

> 저장소 정보를 수정한다.

## 사용자 및 권한

- Organization Role : `ORG_OWNER`

## 사전 조건

- 삭제되지 않은 저장소여야 한다.

## 입력값

| 항목 | 형식 | 필수 여부 | 설명 |
| --- | --- | :---: | --- |

| 저장소 설명 | String | X | 저장소 설명 |

## 처리 절차

1. 사용자 Role을 확인한다.
2. 저장소 존재 여부를 확인한다.
3. 입력값을 검증한다.
4. 저장소 정보를 수정한다.

## 업무 규칙

- `ORG_OWNER`만 수정할 수 있다.
- 삭제되지 않은 저장소여야 한다.

## 처리 결과

- 저장소 정보가 수정된다.

## 예외 처리

| 예외 조건            | 처리             |
|------------------|----------------|
| `ORG_OWNER` 가 아님 | 권한 없음을 반환한다.   |
| 존재하지 않는 저장소      | 존재하지 않음을 반환한다. |

# 📝 2.4.4 저장소 삭제

## 기능 목적

> 저장소를 삭제한다.

## 사용자 및 권한

- Organization Role : `ORG_OWNER`

## 사전 조건

- 저장소가 존재해야 한다.

## 입력값

| 항목 | 형식 | 필수 여부 | 설명 |
| --- | --- | :---: | --- |
| 저장소 ID | Long | O | 삭제할 저장소 |

## 처리 절차

1. 사용자 권한을 확인한다.
2. 저장소 내 구역 존재 여부를 확인한다.
3. 저장소를 삭제 처리한다.

## 업무 규칙

- `OWNER`만 삭제할 수 있다.
- 저장소는 논리 삭제 처리한다.
- 저장소 내 구역이 존재하면 삭제할 수 없다.

## 처리 결과

- [ ] 저장소가 삭제된다.

## 예외 처리

| 예외 조건          | 처리 |
|----------------| --- |
| `OWNER` 권한이 아님 | 삭제를 거부한다. |
| 저장소 내 구역이 존재함  | 삭제를 거부한다. |
| 존재하지 않는 저장소    | 삭제를 거부한다. |
