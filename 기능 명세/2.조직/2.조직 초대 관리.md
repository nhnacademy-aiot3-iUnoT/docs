# 📝 2.2.1 조직원 초대

## 기능 목적

> Owner가 조직원의 이메일을 입력하여 조직 가입 초대 메일을 발송한다.

## 사용자 및 권한

- Role : `OWNER`

## 입력값

| 항목 | 형식 | 필수 | 설명 |
|------|------|:---:|------|
| 이메일 | String | O | 초대할 조직원의 이메일 |

## 처리 절차

1. Owner가 조직원 관리 화면으로 이동한다.
2. 초대할 조직원의 이메일을 입력한다.
3. 시스템은 초대 토큰을 생성한다.
4. 초대 정보를 저장한다.
5. 초대 링크를 생성한다.
6. 입력한 이메일로 초대 메일을 발송한다.

## 업무 규칙

- `OWNER`만 수행할 수 있다.
- 초대 링크는 하나의 조직에만 연결된다.
- 초대 링크는 입력한 이메일에서만 사용할 수 있다.
- 초대 토큰은 만료 시간을 가진다.
- 만료되거나 사용된 토큰은 사용할 수 없다.

## 처리 결과

- [ ] 조직원 초대 메일이 발송된다.
- [ ] 초대 정보가 저장된다.

## 예외 처리

| 예외 조건 | 처리 |
| --- | --- |
| `OWNER` 권한이 아님 | 권한 없음을 반환한다. |
| 이미 조직에 가입된 이메일 | 초대를 거부한다. |
| 이미 초대가 진행 중인 이메일 | 중복 초대를 거부한다. |

# 📝 2.2.2 조직원 회원가입

## 기능 목적

> 조직원이 초대 링크를 통해 계정을 생성하고 조직에 가입한다.

## 사전 조건

- 유효한 초대 토큰이어야 한다.

## 입력값

| 항목   |  필수 |
| ---- | :-: |
| 이름   |  O  |
| 비밀번호 |  O  |


## 처리 절차
1. 사용자가 초대 링크에 접속한다. 
2. 시스템이 초대 토큰을 검증한다. 
3. 조직명을 표시한다. 
4. 회원가입 정보를 입력한다. 
5. Account를 생성한다. 
6. OrganizationMember를 생성한다. 
7. 조직 역할을 MEMBER로 저장한다. 
8. 초대 토큰을 사용 완료 처리한다.

## 업무 규칙

- 조직명은 수정할 수 없다. 
- 조직은 자동으로 지정된다. 
- 초대 토큰은 한 번만 사용할 수 있다. 
- 가입과 동시에 조직원이 된다.

## 처리 결과

- [ ] 회원가입 완료
- [ ] 조직 가입 완료

# 📝 2.2.3 초대 링크 관리

## 기능 목적

> Owner가 발급한 조직원 초대 링크를 조회하고 재발급하거나 만료 처리한다.

## 사용자 및 권한

- Role : `OWNER`

## 처리 절차

1. 사용자 권한을 확인한다.
2. 조직의 초대 링크 목록을 조회한다.
3. 선택한 초대 링크를 복사하거나 재발급 또는 만료 처리한다.
4. 변경 사항을 저장한다.

## 업무 규칙

- `OWNER`만 수행할 수 있다.
- 초대 링크는 동일 조직에 대해서만 유효하다.
- 만료된 초대 링크는 사용할 수 없다.
- 이미 사용된 초대 링크는 재사용할 수 없다.
- 초대 링크를 재발급하면 기존 링크는 자동으로 만료된다.

## 처리 결과

- [ ] 초대 링크 목록을 조회한다.
- [ ] 초대 링크를 복사할 수 있다.
- [ ] 초대 링크를 재발급한다.
- [ ] 초대 링크를 만료 처리한다.

## 예외 처리

| 예외 조건 | 처리 |
| --- | --- |
| `OWNER` 권한이 아님 | 권한 없음을 반환한다. |
| 존재하지 않는 초대 링크 | 존재하지 않음을 반환한다. |
| 이미 만료된 초대 링크 | 만료된 링크임을 반환한다. |
