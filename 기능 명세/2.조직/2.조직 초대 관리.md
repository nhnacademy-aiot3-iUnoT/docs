# 📝 2.2.1 조직원 초대

## 기능 목적

> Owner가 조직원의 이메일을 입력하여 조직 가입 초대 메일을 발송한다.

## 사용자 및 권한
                        
- Organization Role : `ORG_OWNER`

## 입력값

| 항목 | 형식 | 필수 | 설명 |
|------|------|:---:|------|
| 이메일 | String | O | 초대할 조직원의 이메일 |

## 처리 절차

1. Owner가 조직원 초대 페이지로 이동한다.
2. 초대할 조직원의 이메일을 입력한다.
3. 시스템은 초대 토큰을 생성한다.
4. 초대 링크를 생성한다.
5. 초대 정보를 저장한다.
6. 입력한 이메일로 초대 메일을 발송한다.

## 업무 규칙

- `ORG_OWNER`만 수행할 수 있다.
- 초대 링크는 하나의 조직에만 연결된다.
- 초대 토큰은 만료 시간을 가진다.
- 만료되거나 사용된 토큰은 사용할 수 없다.
- 동일 이메일에 ACTIVE 상태의 초대가 존재하면 중복 발급할 수 없다.

## 처리 결과

- [ ] 초대 메일 발송을 시도한다.
- [ ] 초대 정보가 저장된다.

## 예외 처리

| 예외 조건              | 처리 |
|--------------------| --- |
| `ORG_OWNER` 권한이 아님 | 권한 없음을 반환한다. |
| 이미 조직에 가입된 이메일     | 초대를 거부한다. |
| 이미 초대가 진행 중인 이메일   | 중복 초대를 거부한다. |
| 이메일 발송 실패 | 초대는 생성하고 메일 발송 실패 상태를 저장한다. |


# 📝 2.2.2 조직원 회원가입

## 기능 목적

> 조직원이 초대 링크를 통해 계정을 생성하고 조직에 가입한다. (회원가입은 account 담당)
> 회원가입(Account 생성)에 대한 상세 내용은 Account 명세에서 관리한다.

## 사전 조건

- 유효한 초대 토큰이어야 한다.

## 입력값

| 항목   |  필수 |
| ---- | :-: |
| 이름   |  O  |
| 비밀번호 |  O  |


## 처리 절차
1. 사용자가 초대 링크에 접속한다. 
2. 시스템이 초대 토큰을 검증한다. 
3. 조직명을 표시한다. 
4. (회원가입 - Account Server)
7. 조직 상태를 확인한다.
8. 조직이 PENDING이면 OWNER로 등록하고 조직 상태를 ACTIVE로 변경한다.
9. 조직이 ACTIVE이면 MEMBER로 등록한다.
10. 초대 토큰을 사용 완료 처리한다.

## 업무 규칙

- 조직명은 수정할 수 없다. 
- 조직은 자동으로 지정된다. 
- 초대 토큰은 한 번만 사용할 수 있다.

| ------------------ | --------- |

# 📝 2.2.3 초대 링크 관리

## 기능 목적

> Owner가 발급한 조직원 초대 링크를 조회하고 재전송, 재발급 및 만료 처리한다.

## 사용자 및 권한

- Organization Role : `ORG_OWNER`

## 처리 절차

1. 사용자 권한을 확인한다.
2. 조직의 초대 링크 목록을 조회한다.
3. 선택한 초대 링크를 재전송, 재발급 또는 취소 처리한다.
4. 변경 사항을 저장한다.

## 업무 규칙

- `OWNER`만 수행할 수 있다.
- 초대 링크는 동일 조직에 대해서만 유효하다.
- 이미 사용된 or 만료된 초대 링크는 재사용할 수 없다.
- 초대 링크를 재발급하면 기존 링크는 자동으로 만료된다.
- ACTIVE, USED, EXPIRED, CANCELED 상태의 초대 내역을 조회할 수 있다.
- 재전송은 ACTIVE 상태의 초대만 가능하다.
- 만료 시각이 일정 시간(예: 5분) 이하로 남은 경우 재발급을 권장한다.

## 처리 결과

- [ ] 초대 링크 목록을 조회한다.
- [ ] 초대 링크를 재발급한다.
- [ ] 초대 링크를 만료 처리한다.
- [ ] 초대 메일을 재전송한다.

## 예외 처리

| 예외 조건 | 처리 |
| --- | --- |
| `OWNER` 권한이 아님 | 권한 없음을 반환한다. |
| 존재하지 않는 초대 링크 | 존재하지 않음을 반환한다. |
| 이미 만료된 초대 링크 | 만료된 링크임을 반환한다. |
| ACTIVE가 아닌 초대를 재전송 | 재전송할 수 없음을 반환한다.                     |
| 이미 사용된 초대를 재발급     | 재발급할 수 없음을 반환한다. *(정책에 따라 허용한다면 제외)* |
| 취소된 초대를 재전송        | 재전송할 수 없음을 반환한다.                     |
