# 📝 2.5.1 구역 등록

## 기능 목적

> 저장소 내 의약품을 보관할 구역을 등록한다.

## 사용자 및 권한

- `OWNER`

## 사전 조건

- 로그인한 사용자여야 한다.
- 조직의 `OWNER` 권한을 가진 사용자여야 한다.
- 저장소가 존재해야 한다.

## 입력값

| 항목 | 형식 | 필수 여부 | 설명 |
| --- | --- | :---: | --- |
| 저장소 ID | Long | O | 구역을 등록할 저장소 |
| 구역명 | String | O | 동일 저장소 내 중복 불가 |
| 구역 설명 | String | X | 구역에 대한 설명 |
| 센서 임계값 설정 정보 | Object  |   X   | 구역별 센서 기준값 설정 |
| 온도 최소/최대 기준값 | Double  |   X   | 온도 허용 범위      |
| 습도 최소/최대 기준값 | Double  |   X   | 습도 허용 범위      |
| 조도 최소/최대 기준값 | Double  |   X   | 조도 허용 범위      |
| 문 열림 지속 시간   | Integer |   X   | 문 열림 상태 판단 시간 |


## 처리 절차

1. 사용자 권한을 확인한다.
2. 구역 상태를 확인한다.
3. 입력값을 검증한다.
4. 센서 임계값 유효성을 검증한다.
5. 구역 정보를 수정한다.

## 업무 규칙

- `OWNER`만 등록할 수 있다.
- 저장소가 존재해야 한다.
- 동일 저장소 내에서 구역명은 중복될 수 없다.
- 구역별 센서 임계값을 설정할 수 있다. 
- 온도, 습도, 조도 센서는 최소/최대 임계값을 설정할 수 있다. 
- 문 열림 센서는 열린 상태가 지속되는 시간을 기준으로 알림을 판단한다. 
- 설정된 임계값을 초과한 상태가 지정된 시간 이상 유지될 경우 알림을 발생한다. 
- 임계값은 구역 단위로 관리한다.
- 최소 임계값은 최대 임계값보다 클 수 없다.
- 알림 주기는 0보다 큰 값이어야 한다.

## 처리 결과

- [ ] 새로운 구역이 생성된다.
- [ ] 구역 별 임계값 정보가 설정된다.

## 예외 처리

| 예외 조건 | 처리             |
| --- |----------------|
| `OWNER` 권한이 아님 | 권한 없음을 반환한다.   |
| 저장소가 존재하지 않음 | 존재하지 않음을 반환한다. |
| 동일 저장소 내 구역명이 중복됨 | 중복임을 반환한다.     |

# 📝 2.5.2 구역 조회

## 기능 목적

> 저장소에 등록된 구역 정보를 조회한다.

## 사용자 및 권한

- 사용자는 자신이 소속된 조직의 저장소만 조회할 수 있다.

## 사전 조건

- 로그인한 사용자여야 한다.
- 조직에 소속되어 있어야 한다.

## 입력값

| 항목 | 형식 | 필수 여부 | 설명 |
| --- | --- | :---: | --- |
| 저장소 ID | Long | O | 조회할 저장소 |
| 구역 ID | Long | X | 상세 조회 시 사용 |

## 처리 절차

1. 조직 소속 여부를 확인한다.
2. 저장소를 조회한다.
3. 구역 정보를 조회한다.
4. 조회 결과를 반환한다.

## 업무 규칙

- 조직 구성원만 조회할 수 있다.
- 저장소별 구역 목록을 조회할 수 있다.
- 구역 상세 정보를 조회할 수 있다.
- 삭제되지 않은 구역만 조회한다.

## 처리 결과

- [ ] 구역 목록 또는 상세 정보를 반환한다.

## 예외 처리

| 예외 조건 | 처리 |
| --- | --- |
| 조직 구성원이 아님 | 조회를 거부한다. |
| 저장소가 존재하지 않음 | 조회를 거부한다. |
| 존재하지 않는 구역 | 조회를 거부한다. |

## 입력값

# 📝 2.5.4 구역 삭제

## 기능 목적

> 구역을 비활성화한다.

## 사용자 및 권한

- `OWNER`

## 사전 조건

- 구역이 존재해야 한다.

## 입력값

| 항목 | 형식 | 필수 여부 | 설명 |
| --- | --- | :---: | --- |
| 구역 ID | Long | O | 삭제할 구역 |

## 처리 절차

1. 사용자 권한을 확인한다.
2. 구역 내 의약품 존재 여부를 확인한다.
3. 구역을 삭제 처리한다.

## 업무 규칙

- `OWNER`만 삭제할 수 있다.
- 구역 내 의약품이 존재하면 삭제할 수 없다.
- 구역은 논리 삭제한다.

## 처리 결과

- [ ] 구역이 삭제된다.

## 예외 처리

| 예외 조건 | 처리             |
| --- |----------------|
| `OWNER` 권한이 아님 | 권한 없음을 반환한다.   |
| 구역 내 의약품이 존재함 | 삭제를 거부한다.      |
| 존재하지 않는 구역 | 존재하지 않음을 반환한다. |
