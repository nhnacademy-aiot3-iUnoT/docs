# Enum 정의

## 조직 상태

| 값         | 설명               |
|-----------|------------------|
| PENDING   | ADMIN이 생성만  한 상태 |
| ACTIVE    | 정상 운영            |
| INACTIVE  | 일시 비활성화          |
| SUSPENDED | 폐쇄/계약 종료         |

---

## 초대 상태 (토큰 상태)

| 값      | 설명     |
|--------|--------|
| ACTIVE | 토큰 유효  |
| USED | 사용 완료  |
| EXPIRED | 만료     |
| CANCELED | 초대 취소  |


---

## 조직 내 역할

| 값          | 설명               |
|------------|------------------|
| ORG_OWNER  | 조직 생성자 & role 부여 |
| ORG_MEMBER | 일반 조직원           |

---

## 저장소 상태, 부서 상태
| 값        | 설명   |
|----------|------|
| ACTIVE   | 활성화  |
| INACTIVE | 비활성화 |
| CLOSED | 삭제 |

---

## 구역 환경 이상 상태
| 값        | 설명 |
|----------|----|
| NORMAL   | 정상 |
| WARNING  | 주의 |
| CRITICAL | 위험 |
