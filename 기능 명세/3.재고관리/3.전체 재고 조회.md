# 📝 3.1 전체 재고 조회

## 기능 목적

> 사용자가 소속된 조직이 보유한 의약품 재고를 저장소별로 조회할 수 있도록한다.
> 동일한 저장소에 제조번호, 실제 유통기한 또는 보관 구역이 다른 재고가 여러 건 존재하는 경우 이를 
> 의약품 단위로 집계하여 제품명,저장소,출고 가능 수량 및 재고 현황을 제공한다.


## 사용자 및 권한

- 로그인한 조직 소유자 `OWNER`, 재고 관리 권한을 부여받은 `MEMBER`
- 사용자는 자신이 현재 소속된 조직의 재고만 조회할 수 있다.
- 다른 조직의 재고는 조회할 수 없다.
- 권한이 없는 사용자는 전체 재고 화면에 접근할 수 없다.



## 사전 조건

- 사용자가 현재 조직에 정상적으로 소속되어 있어야 한다.
- 사용자에게 재고 조회 권한이 있어야 한다.
- 조직에 의약품 재고 정보가 등록되어 있어야 한다.
- 의약품, 저장소, 보관 구역 및 재고 정보가 데이터베이스에 정상적으로 저장되어 있어야 한다.



## 입력값

- 없음

## 조회 데이터

| 데이터         | 조회 목적                                      |
| ----------- | ------------------------------------------ |
| 의약품 정보      | 재고에 연결된 제품명을 조회한다.                         |
| 저장소 정보      | 재고가 보관된 저장소명을 조회한다.                        |
| 재고 정보       | 현재 수량, 제조번호, 실제 유통기한, 보관 구역 및 재고 상태를 조회한다. |
| 재고 부족 알림 설정 | 저장소별 의약품의 재고 부족 여부를 판단한다.                  |
| 환경 검토 정보    | 환경 이상으로 검토 중인 재고가 존재하는지 확인한다.              |


## 처리 절차

1. 현재 로그인한 사용자의 조직 소속 상태와 재고 조회 권한을 확인한다.
2. 현재 사용자가 소속된 조직을 확인한다.
3. 재고 데이터베이스에서 현재 조직에 속한 재고 정보를 조회한다.
4. 각 재고에 연결된 의약품 정보를 조회하여 제품명을 확인한다.
5. 각 재고에 연결된 저장소 정보를 조회하여 저장소명을 확인한다.
6. 조회된 재고를 의약품 + 저장소 단위로 그룹화한다.
7. 각 그룹에 포함된 제조번호별, 실제 유통기한별 및 보관 구역별 재고의 출고 가능 여부를 확인한다.
8. 출고 가능한 재고의 현재 수량을 합산하여 출고 가능 수량을 계산한다.
9. 저장소별 재고 부족 설정, 실제 유통기한 상태 및 환경 검토 상태를 조회한다.
10. 조회된 정보를 기준으로 재고 현황을 판단한다.
11. 제품명, 저장소, 출고 가능 수량 및 재고 현황을 전체 재고 목록으로 반환한다.
12. 현재 수량이 남아 있는 재고를 기본 목록에 표시한다.
13. 소진 상태와 폐기 완료 상태의 재고는 기본 목록에서 제외한다.


## 전체 목록 표시 항목
| 항목       | 설명                                        |
| -------- | ----------------------------------------- |
| 제품명      | 의약품 정보에 저장된 제품명을 표시한다.                    |
| 저장소      | 해당 의약품 재고가 보관된 저장소명을 표시한다.                |
| 출고 가능 수량 | 해당 저장소에서 현재 출고 가능한 재고 수량의 합계를 표시한다.       |
| 재고 현황    | 정상, 재고 부족, 유통기한 임박, 만료, 검토 중 등의 상태를 표시한다. |
| 상세보기     | 제조번호, 실제 유통기한, 보관 구역 및 수량별 상세 화면으로 이동한다.  |


## 업무 규칙

- 전체 재고 목록은 현재 로그인한 사용자가 소속된 조직을 기준으로 조회한다.
- 다른 조직의 재고는 조회 결과에 포함하지 않는다.
- 전체 재고 목록의 조회 단위는 의약품 + 저장소로 한다.
- 같은 의약품이 여러 저장소에 존재하면 저장소별로 별도의 행으로 표시한다. 
- 동일한 저장소에 제조번호, 실제 유통기한 또는 보관 구역이 다른 재고가 여러 건 존재하면 하나의 행으로 집계한다.
- 출고 가능 수량은 실제 출고할 수 있는 재고의 현재 수량만 합산한다. 
- 폐기 완료 출고 불가 상태의 재고는 출고 가능 수량에서 제외한다. 
- 유통기한 임박 재고가 출고 가능한 정책이면 출고 가능 수량에 포함한다.
- 재고 부족 상태는 저장소 + 의약품 단위로 설정된 기준을 사용하여 판단한다.
- 하나의 의약품과 저장소에 여러 상태가 존재하는 경우 재고 현황은 복수 상태로 표시할 수 있다.
- 폐기 완료 상태의 재고는 기본 목록에 표시하지 않는다.
- 목록의 수량은 조회 시점의 데이터베이스 값을 기준으로 계산한다.



## 처리 결과

- 현재 조직의 재고가 의약품 + 저장소 단위로 조회된다.
- 전체 재고 목록에 다음 정보가 표시된다.
  - 제품명
  - 저장소
  - 출고 가능 수량
  - 재고 현황
- 동일한 저장소에 나뉘어 있는 출고 가능한 재고 수량이 합산되어 표시된다.
- 재고 부족,정상, 검토 중 상태가 재고 현황에 표시된다.
- 사용자는 상세보기를 통해 제조번호, 실제 유통기한, 보관 구역 및 현재 수량을 확인할 수 있다.



## 예외 처리

| 예외 조건                               | 처리                                                   |
| ----------------------------------- | ---------------------------------------------------- |
| 로그인하지 않은 사용자가 조회를 요청함               | 로그인 필요 메시지를 표시하고 조회 요청을 거부한다.                        |
| 사용자가 조직에 소속되어 있지 않거나 소속 상태가 유효하지 않음 | 전체 재고 조회 기능에 대한 접근을 제한한다.                            |
| 재고 조회 권한이 없는 사용자가 조회를 요청함           | 권한이 없다는 메시지를 표시하고 조회 요청을 거부한다.                       |
| 현재 조직에 등록된 재고가 없음                   | `등록된 재고가 없습니다.` 메시지를 표시한다.                           |
| 재고에 연결된 의약품 정보를 찾을 수 없음             | 해당 재고를 비정상 데이터로 기록하고 목록에서 제외하거나 제품명을 `정보 없음`으로 표시한다. |
| 재고에 연결된 저장소 정보를 찾을 수 없음             | 해당 재고를 비정상 데이터로 기록하고 목록에서 제외한다.                      |
| 재고 수량 또는 상태 집계 중 오류가 발생함            | 조회를 중단하고 일시적인 오류 메시지를 표시한다.                          |
| 데이터베이스 조회에 실패함                      | `재고 정보를 조회하는 중 오류가 발생했습니다.` 메시지를 표시한다.               |



# 📝 3.2 전체 재고 검색 및 필터링

## 기능 목적

> 전체 재고 목록에서 제품명, 저장소 및 재고 현황 조건을 사용하여 사용자가 필요한 재고를 빠르게 조회할 수 있도록 한다.


## 사용자 및 권한

- 전체 재고 목록 조회 권한을 가진 사용자만 검색 및 필터 기능을 사용할 수 있다.
- 사용자는 자신이 소속된 조직의 재고만 검색할 수 있다.
- 저장소 필터에는 현재 조직에 속한 저장소만 표시한다.



## 사전 조건

- 사용자가 전체 재고 목록 화면에 접근한 상태여야 한다.
- 사용자에게 재고 조회 권한이 있어야 한다.
- 전체 재고 목록을 조회할 수 있는 데이터가 존재해야 한다.



## 입력값

| 항목    | 형식  | 필수 여부 | 설명                                        |
| ----- | --- | :---: | ----------------------------------------- |
| 제품명   | 문자열 |   선택  | 제품명의 전체 또는 일부를 입력한다.                      |
| 저장소   | 선택값 |   선택  | 현재 조직의 저장소 중 하나를 선택한다.                    |
| 재고 현황 | 선택값 |   선택  | 정상, 재고 부족, 유통기한 임박, 만료, 검토 중 등의 상태를 선택한다. |



## 처리 절차

1. 시스템은 사용자가 입력하거나 선택한 제품명, 저장소 및 재고 현황 조건을 확인한다.
2. 제품명이 입력된 경우 앞뒤 공백을 제거한다.
3. 저장소가 선택된 경우 해당 저장소가 현재 조직에 속하는지 확인한다.
4. 재고 현황이 선택된 경우 시스템에서 정의한 상태인지 확인한다.
5. 시스템은 현재 조직의 재고 목록에 입력된 검색 및 필터 조건을 적용한다.
6. 제품명이 입력된 경우 해당 문자열이 포함된 제품의 재고만 조회한다.
7. 저장소가 선택된 경우 해당 저장소에 보관된 재고만 조회한다.
8. 재고 현황이 선택된 경우 해당 현황을 가진 재고만 조회한다.
9. 여러 조건이 입력된 경우 모든 조건을 만족하는 재고를 조회한다.
10. 시스템은 조회된 재고를 의약품 + 저장소 단위로 집계한다.
11. 시스템은 제품명, 저장소, 출고 가능 수량 및 재고 현황을 검색 결과로 반환한다.
12. 사용자가 초기화를 선택하면 모든 검색 및 필터 조건을 제거하고 전체 재고 목록을 다시 조회한다.


## 업무 규칙

- 제품명, 저장소 및 재고 현황은 모두 선택 입력값으로 처리한다.
- 조건을 입력하지 않으면 전체 재고 목록을 조회한다.
- 제품명은 전체 또는 일부 문자열로 검색할 수 있다.
- 저장소 필터에는 현재 조직에 속한 저장소만 표시한다.
- 재고 현황은 시스템에서 정의한 상태만 선택할 수 있다.
- 여러 조건이 입력된 경우 AND 조건으로 적용한다.
- 필터링 이후에도 목록의 집계 단위는 의약품 + 저장소로 유지한다.
- 검색 및 필터링은 다른 조직의 재고에 적용할 수 없다.
- 검색 결과의 출고 가능 수량과 재고 현황은 조회 시점의 데이터를 기준으로 다시 계산한다.




## 처리 결과

- 제품명 조건과 일치하는 재고 목록이 표시된다.
- 선택한 저장소에 보관된 재고 목록이 표시된다.
- 선택한 재고 현황에 해당하는 재고 목록이 표시된다.
- 여러 조건을 입력한 경우 모든 조건을 만족하는 재고만 표시된다.
- 검색 조건을 초기화하면 현재 조직의 전체 재고 목록이 다시 표시된다.



## 예외 처리

| 예외 조건                        | 처리                                     |
| ---------------------------- | -------------------------------------- |
| 제품명이 공백으로만 구성됨               | 공백을 제거한 후 제품명 조건을 적용하지 않는다.            |
| 제품명이 허용된 최대 길이를 초과함          | 허용 가능한 길이를 안내하고 검색을 수행하지 않는다.          |
| 선택한 저장소가 현재 조직에 속하지 않음       | 해당 저장소 조건을 적용하지 않고 요청을 거부한다.           |
| 존재하지 않거나 사용할 수 없는 저장소가 선택됨   | 저장소 목록을 다시 조회하도록 안내한다.                 |
| 정의되지 않은 재고 현황이 전달됨           | 유효한 재고 현황을 선택하도록 안내하고 조회를 수행하지 않는다.    |
| 검색 및 필터 조건과 일치하는 재고가 없음      | `조회 조건과 일치하는 재고가 없습니다.` 메시지를 표시한다.     |
| 검색 또는 필터 처리 중 데이터베이스 오류가 발생함 | `재고 정보를 조회하는 중 오류가 발생했습니다.` 메시지를 표시한다. |
