# 📝 2. 의약품 입고 등록

## 기능 목적

> 입고된 의약품을 제조번호, 실제 유통기한 및 보관 위치별로 구분하여 재고를 정확하게 관리하기 위한 기능이다.
> 입고에 따른 재고 수량 변동과 처리 담당자 이력을 자동으로 기록하여 재고 변경 근거를 추적할 수 있도록 한다.

## 사용자 및 권한

- 로그인한 사용자만 이용할 수 있다. 
- 다음 사용자만의 의약품 입고를 등록할 수 있다.
    - 조직 소유자 `OWNER`
    - 재고 관리 권한을 부여받은 `MEMBER`
- 사용자는 자신이 소속된 조직의 저장소에만 입고를 등록할 수 있다. 
- 권한이 없는 사용자는 입고 등록 화면에 접근할 수 없다. 
- 기존 의약품의 환경 기준 수정은 환경 기준 수정 권한을 가진 사용자만 가능하다.


## 사전 조건

- 사용자가 로그인된 상태여야 한다.
- 사용자에게 입고 등록 권한이 있어야 한다.
- 의약품 공공데이터가 시스템의 의약품 정보 데이터베이스에 저장되어 있어야 한다.
- 조직에 사용 가능한 저장소가 등록되어 있어야 한다.
- 선택한 저장소에 사용 가능한 보관 구역이 등록되어 있어야 한다. 
- 선택한 보관 구역에 온도, 습도, 조도 등의 환경 기준이 설정되어 있어야 한다.
- 입고 대상 의약품이 조직에서 처음 관리되는 의약품인 경우, 입고 과정에서 조직 관리 의약품으로 등록할 수 있어야 한다.




## 입력값

### 의약품 검색

| 항목     | 형식  | 필수 여부 | 설명                        |
| ------ | --- | :---: | ------------------------- |
| 검색어    | 문자열 |   필수  | 제품명 또는 품목기준코드를 입력한다.      |
| 의약품 선택 | 선택값 |   필수  | 검색 결과에서 실제 입고할 의약품을 선택한다. |


### 의약품 자동 조회 정보 

| 항목       | 공공데이터 필드         | 형식  | 필수 여부 | 설명                             |
| -------- | ---------------- | --- | :---: | ------------------------------ |
| 품목기준코드   | `ITEM_SEQ`       | 문자열 |   자동  | 공공데이터에서 의약품을 식별하는 코드이다.        |
| 제품명      | `ITEM_NAME`      | 문자열 |   자동  | 의약품 제품명이다.                     |
| 업체명      | `ENTP_NAME`      | 문자열 |   자동  | 의약품 제조 또는 수입 업체명이다.            |
| 저장방법     | `STORAGE_METHOD` | 문자열 |   자동  | 저장소 및 보관 구역 선택 시 참고하는 보관 정보이다. |
| 허가된 유효기간 | `VALID_TERM`     | 문자열 |   자동  | 제조일을 기준으로 허가된 사용 가능 기간이다.      |
| 성분·함량 정보 | `MATERIAL_NAME`  | 문자열 |   자동  | 의약품의 주요 성분 및 함량 정보이다.          |


- 자동 조회된 의약품 정보는 사용자가 수정할 수 없다.
- 저장 방법은 환경 기준 설정을 위한 참고 정보로만 표시한다.



### 실제 입고 정보

| 항목      | 형식    | 필수 여부 | 설명                                   |
| ------- | ----- | :---: | ------------------------------------ |

| 실제 유통기한 | 날짜    |   필수  | 실제 제품 포장에 표시된 유통기한을 입력한다.            |
| 입고 수량   | 양의 정수 |   필수  | 실제 입고되는 의약품 수량을 입력한다.                |
| 저장소     | 선택값   |   필수  | 사용자가 소속된 조직의 사용 가능한 저장소 중 하나를 선택한다.  |
| 보관 구역   | 선택값   |   필수  | 선택한 저장소에 속한 사용 가능한 보관 구역 중 하나를 선택한다. |

### 의약품 환경 기준

| ------------- | -------- | :--------: | -------------------------------------------- |

| 최대 온도         | 숫자       | 필수 | 의약품의 허용 가능한 최대 온도를 입력한다.                     |
| 최소 습도         | 숫자       | 필수 | 의약품의 허용 가능한 최소 습도를 입력한다.                     |
| 최대 습도         | 숫자       | 필수 | 의약품의 허용 가능한 최대 습도를 입력한다.                     |
| 최소 조도         | 숫자       |     선택     | 의약품의 허용 가능한 최소 조도를 입력한다.                     |
| 최대 조도         | 숫자       | 필수 | 의약품의 허용 가능한 최대 조도를 입력한다.                     |

- 조직에서 처음 등록하는 의약품은 사용자가 공공데이터의 저장방법을 참고하여 환경 기준을 입력한다.
- 기존 등록 의약품은 저장된 환경 기준을 자동으로 불러온다.
- 입고 등록 권한이 있는 사용자는 기존 의약품 환경 기준을 수정할 수 있다.
- 문 열림 감지 여부와 문 열림 허용 시간은 의약품 환경 기준에 포함하지 않는다.

| 항목    | 형식  | 필수 여부 | 설명                                         |

| 보관 구역 | 선택값 |   필수  | 선택한 저장소 안에서 의약품 환경 기준을 충족하는 구역 중 하나를 선택한다. |

- 의약품 환경 기준이 설정되거나 기준이 조회된 이후 저장소를 선택할 수 있다.
- 저장소를 선택하면 시스템은 해당 저장소에 속한 보관 구역의 환경 임계치를 조회한다.
- 시스템은 온도, 습도 및 조도 기준을 충족하는 보관 구역만 선택 가능하게 제공한다.
- 문 열림 임계치는 보관 구역 선택을 위한 의약품 적합성 판정 조건에 포함하지 않는다.

## 보관 구역 적합성 판정
보관 구역의 환경 관리 범위가 의약품의 허용 범위 안에 포함되어야 한다.


### 온도 

#### 적합한 경우
의약품이 허용하는 온도가 1~30℃이고, 구역이 5~25℃로 관리된다면:
```
의약품 허용 범위: 1 ─────────────── 30
구역 관리 범위:       5 ─────── 25
```
#### 부적합한 경우
의약품이 냉장 상태인 2~8℃만 허용하는데, 구역이 1~30℃로 관리된다면:

```
의약품 허용 범위:   2 ─── 8
구역 관리 범위:   1 ─────────────── 30
```
의약품 허용 범위보다 구역 관리 범위가 좁고 그 안에 들어와야 함.



### 습도

```
의약품 최소 습도 ≤ 구역 최소 습도
구역 최대 습도 ≤ 의약품 최대 습도
```

### 조도 
최소 조도를 설정한 경우:
```
의약품 최소 조도 ≤ 구역 최소 조도
구역 최대 조도 ≤ 의약품 최대 조도
```
최소 조도를 설정하지 않은 경우:
```
구역 최대 조도 ≤ 의약품 최대 조도
```
- 온도,습도 또는 조도 중 하나라도 기준을 충족하지 않으면 해당 보관 구역은 선택할 수 없다.
- 문 열림 임계치는 구역 운영 기준이므로 위 적합성 판정에 포함하지 않는다.



## 동일 재고 판정 기준
다음 조건이 모두 동일한 경우 동일 재고로 판단한다.
- 동일 조직
- 동일 의약품
- 동일 제조번호
- 동일 실제 유통기한
- 동일 저장소
- 동일 보관 구역

동일 재고가 존재하면 신규 재고를 생성하지 않고 기존 재고 수량에 입고 수량을 합산한다.

다음 중 하나라도 다르면 별도 재고로 생성한다.
- 재조 번호
- 실제 유통기한
- 저장소
- 보관 구역

## 처리 절차


의약품 정보 

------------



의약품 입고 등록
18. 사용자가 입고 등록 버튼을 선택한다.
19. 시스템은 권한, 필수값, 입력 형식, 저장소·구역 상태 및 최신 환경 기준 적합성을 최종 검증한다.
20. 시스템은 동일 재고가 기존에 존재하는지 확인한다.
21. 조직에서 처음 관리하는 의약품이면 조직 관리 의약품 정보와 환경 기준을 저장한다.
22. 기존 의약품의 환경 기준이 변경된 경우 변경된 값을 반영한다.
23. 동일 재고가 없으면 신규 재고를 생성한다.
24. 동일 재고가 있으면 기존 재고 수량에 입고 수량을 합산한다.
25. 시스템은 입고 전 수량과 입고 후 수량을 계산한다.
26. 시스템은 거래 유형이 INBOUND인 재고 변동 내역을 생성한다.
27. 시스템은 입고 정보, 처리 담당자 및 처리 일시를 변동 내역에 기록한다.
28. 시스템은 실제 유통기한을 기준으로 재고의 만료 여부를 판단한다.
29. 시스템은 해당 저장소의 의약품 출고 가능 수량을 다시 계산한다.
30. 시스템은 저장소별 재고 부족 알림 상태를 갱신한다.
31. 입고 처리가 완료되면 입고 등록이 완료되었습니다. 메시지를 표시한다.
32. 시스템은 사용자를 전체 재고 목록으로 이동시킨다.






## 요구사항

### 1.1 의약품 검색 및 조회
- [ ] 사용자는 전체 재고 목록 상단의 입고 등록 버튼을 통해 입고 등록 화면으로 이동할 수 있어야 한다.
- [ ] 사용자는 제품명 또는 품목기준코드로 입고할 의약품을 검색할 수 있어야 한다.
- [ ] 시스템은 외부 공공데이터 API를 직접 호출하지 않고 내부 의약품 데이터베이스에서 검색해야 한다.
- [ ] 사용자는 검색 결과에서 입고할 의약품을 선택할 수 있어야 한다.
- [ ] 시스템은 선택한 의약품의 다음 정보를 자동으로 표시해야 한다.
  - 품목기준코드
  - 제품명
  - 업체명
  - 저장방법
  - 허가된 유효기간
  - 성분·함량 정보
- [ ] 자동 조회된 의약품 정보는 사용자가 직접 수정할 수 없어야 한다.
- [ ] 저장방법은 의약품 환경 기준을 설정하기 위한 참고 정보로 표시해야 한다.

### 1.2 조직 관리 의약품 확인

- [ ] 시스템은 선택한 의약품이 현재 조직에서 관리 중인 의약품인지 확인해야 한다.
- [ ] 해당 조직에서 처음 입고하는 의약품은 입고 과정에서 조직 관리 의약품으로 등록할 수 있어야 한다.
- [ ] 기존 등록 의약품은 저장된 환경 기준과 유통기한 임박 알림 설정을 자동으로 불러와야 한다.



### 1.3 의약품 환경 기준 설정

- [ ] 사용자는 공공데이터의 저장방법을 참고하여 다음 환경 기준을 설정할 수 있어야 한다.
  - 최소 온도
  - 최대 온도
  - 최소 습도
  - 최대 습도
  - 최소 조도
  - 최대 조도

- [ ] 최소 조도는 선택적으로 입력할 수 있어야 한다.
- [ ] 조직에서 처음 관리하는 의약품은 환경 기준을 새로 설정할 수 있어야 한다.
- [ ] 기존 등록 의약품은 저장된 환경 기준을 자동으로 표시해야 한다.
- [ ] 입고 등록 권한이 있는 사용자는 기존 의약품 환경 기준을 변경할 수 있어야 한다.
- [ ] 환경 기준은 제조번호나 유통기한별이 아닌 조직과 의약품의 조합별로 관리해야 한다.
- [ ] 문 열림 감지 여부와 허용 시간은 의약품 환경 기준에 포함하지 않아야 한다. 

### 1.4 저장소 및 보관 구역 선택

- [ ] 의약품 환경 기준이 설정되거나 기존 기준이 조회된 이후 저장소를 선택할 수 있어야 한다.
- [ ] 사용자는 자신이 소속된 조직의 사용 가능한 저장소만 선택할 수 있어야 한다.
- [ ] 저장소 선택 시 시스템은 해당 저장소에 속한 사용 가능한 보관 구역을 조회해야 한다.
- [ ] 시스템은 각 보관 구역의 온도·습도·조도 관리 범위를 의약품 환경 기준과 비교해야 한다.
- [ ] 시스템은 의약품 환경 기준을 충족하는 보관 구역만 선택할 수 있도록 제공해야 한다.
- [ ] 선택 가능한 보관 구역이 없는 경우 입고를 진행할 수 없어야 한다.
- [ ] 사용자는 보관 구역의 환경 임계치를 입고 화면에서 조회할 수 있어야 한다.
- [ ] 보관 구역의 환경 임계치는 입고 화면에서 수정할 수 없어야 한다.
- [ ] 최종 입고 등록 시 보관 구역의 최신 환경 임계치를 다시 조회하여 적합성을 검증해야 한다.

### 1.5 실제 입고 정보 입력
- [ ] 사용자는 다음 정보를 입력할 수 있어야 한다.
  - 제조번호
  - 실제 유통기한
  - 입고 수량
  - 메모

- [ ] 제조번호, 실제 유통기한 및 입고 수량은 필수로 입력해야 한다. 
- [ ] 메모는 선택적으로 입력할 수 있어야 한다. 
- [ ] 실제 유통기한은 현재 날짜 이후의 날짜만 입력할 수 있어야 한다.
- [ ] 입고 수량은 1 이상의 정수만 입력할 수 있어야 한다.


### 1.6 재고 생성 및 수량 반영

- [ ] 시스템은 입력된 정보를 기준으로 동일 재고가 존재하는지 확인해야 한다.
- [ ] 동일 재고가 존재하지 않으면 신규 재고를 생성해야 한다.
- [ ] 동일 재고가 존재하면 신규 재고를 생성하지 않고 기존 재고 수량에 입고 수량을 합산해야 한다.
- [ ] 신규 재고의 최초 수량은 사용자가 입력한 입고 수량으로 설정해야 한다.
- [ ] 신규 재고의 초기 상태는 `정상`으로 설정해야 한다.

### 1.7 입고 변동 내역 기록
- [ ] 입고 완료 시 거래 유형이 `INBOUND`인 재고 변동 내역을 생성해야 한다.
- [ ] 입고 변동 내역에는 다음 정보를 기록해야 한다.
  - 대상 의약품
  - 제조번호
  - 실제 유통기한
  - 저장소
  - 보관 구역
  - 입고 전 수량
  - 입고 수량
  - 입고 후 수량
  - 처리 담당자
  - 처리 일시
  - 메모
- [ ] 처리 담당자는 현재 로그인한 사용자로 자동 기록해야 한다.
- [ ] 처리 일시는 서버에서 입고 처리가 완료된 시각으로 자동 기록해야 한다.
- [ ] 처리 담당자와 처리 일시는 사용자가 직접 입력하거나 수정할 수 없어야 한다.

### 1.8 입고 후 알림 재판정
- [ ] 입고 완료 후 해당 재고의 유통기한 임박 여부를 다시 판단해야 한다.
- [ ] 유통기한 임박 알림을 사용하지 않는 의약품은 임박 알림 생성 대상에서 제외해야 한다.
- [ ] 입고 완료 후 저장소별 의약품 수량을 다시 계산해야 한다.
- [ ] 재계산된 수량을 기준으로 재고 부족 알림 상태를 다시 판단해야 한다.
- [ ] 입고로 재고 부족 상태가 해소되면 기존 재고 부족 알림을 해제해야 한다. 


### 1.9 입고 완료 후 재고 목록 반영
- [ ] 입고 등록이 완료되면 사용자를 재고 전체 화면으로 이동시켜야 한다.
- [ ] 신규 입고된 의약품은 재고 전체 화면에서 표시해야 한다.
- [ ] 재고 전체 화면은 의약품 단위로 재고를 표시해야 한다.
- [ ] 동일한 의약품이 같은 저장소 내에서 제조번호, 유통기한 또는 보관 구역별로 나뉘어 있는 경우, 출고 가능한 재고 수량을 합산하여 표시한다.
- [ ] 재고 전체 화면에는 해당 조직이 보유한 의약품의 전체 저장소 수량을 표시해야 한다.
- [ ] 사용자는 재고 전체 화면에서 의약품 상세 화면으로 이동하여 저장소·보관 구역·제조번호별 수량을 확인할 수 있어야 한다.

## 처리 결과

- 조직에서 처음 관리하는 의약품이면 조직 관리 의약품 정보가 생성된다.
- 기존 등록 의약품의 설정을 변경한 경우 변경된 값이 반영된다.
- 동일 재고가 존재하지 않으면 신규 재고가 생성된다.
- 동일 재고가 존재하면 기존 재고 수량에 입고 수량이 합산된다.
- 신규 재고의 최초 수량은 입력한 입고 수량으로 설정된다.
- 신규 재고의 초기 상태는 `정상`으로 설정된다.
- 입·출고 내역에 거래 유형이 `INBOUND`인 입고 처리 내역이 생성된다.
- 입고 완료 후 재고 전체 화면에 표시된다.
- 재고 전체 화면에는 해당 의약품의 전체 저장소 수량이 표시된다.
- 전체 저장소 수량은 해당 조직 내 동일 의약품의 현재 재고를 합산하여 계산한다.
- 사용자는 재고 상세 화면에서 다음 정보를 확인할 수 있다.
  - 제품명
  - 업체명
  - 저장소 
  - 전체 수량
  - 출고 가능 수량
  - 재고 현황
  - 상세보기
- 입고 후 재고 부족 여부가 다시 계산된다.

| 최소 습도가 최대 습도보다 큰 경우                 | 올바른 습도 범위를 입력하도록 안내한다.                  |
| 최소 조도가 최대 조도보다 큰 경우                 | 올바른 조도 범위를 입력하도록 안내한다.                  |

| 선택한 저장소에 사용 가능한 보관 구역이 없는 경우        | 사용 가능한 보관 구역이 없다고 안내하고 입고를 제한한다.        |

| 보관 구역을 선택하지 않은 경우                   | 입고할 보관 구역을 선택하도록 안내한다.                  |

| 보관 구역의 습도 범위가 의약품 기준을 충족하지 않는 경우    | 해당 구역을 선택 대상에서 제외한다.                    |
| 보관 구역의 조도 범위가 의약품 기준을 충족하지 않는 경우    | 해당 구역을 선택 대상에서 제외한다.                    |

| 동일 재고에 동시에 입고 요청이 발생한 경우            | 최신 재고 수량을 기준으로 안전하게 반영하도록 동시성 제어를 수행한다. |

| 환경 기준 또는 알림 설정 저장에 실패한 경우           | 전체 처리를 롤백하고 입고 등록 실패 메시지를 표시한다.         |
| 신규 재고 생성에 실패한 경우                    | 전체 처리를 롤백하고 입고 등록 실패 메시지를 표시한다.         |
| 기존 재고 수량 증가에 실패한 경우                 | 전체 처리를 롤백하고 입고 등록 실패 메시지를 표시한다.         |

| 입고 처리 도중 시스템 오류가 발생한 경우             | 전체 작업을 롤백하고 잠시 후 다시 시도하도록 안내한다.         |
