# 📝 2. 의약품 입고 등록


## 기능 목적

> 사용자가 선택한 의약품의 제조번호, 실제 유통기한, 입고 수량 및 보관 위치를 시스템에 등록하여 현재 재고에 반영한다.
> 입고에 따른 재고 수량 변동을 `INBOUND` 유형의 변동 내역으로 기록하여 재고 변경 근거와 처리 이력을 추적할 수 있도록 한다.



## 사용자 및 권한

- 로그인한 `OWNER` 또는 재고관리 권한을 가진 조직 사용자가 이용할 수 있다.
- 사용자는 자신이 소속된 조직의 저장소와 보관 구역에만 입고할 수 있다.
- 입고 처리자는 현재 로그인한 사용자로 기록한다.



## 사전 조건

- 사용자에게 재고관리 권한이 부여되어 있어야 한다.
- 입고할 의약품이 내부 의약품 데이터베이스에 존재해야 한다.
- 입고할 저장소가 현재 조직에 속해 있어야 한다.
- 입고할 저장소와 보관 구역이 사용 가능한 상태여야 한다.

| 항목  | 형식      |  필수 여부 | 설명                           |
| --- |---------| :----: | ---------------------------- |
| 의약품 | String  |   필수   | 내부 의약품 데이터베이스에서 선택한 의약품의 식별값 |

| 최소 온도 | Decimal | 조건부 필수 | 조직에서 처음 관리하는 의약품의 최소 허용 온도   |

| 최대 습도 | Decimal | 조건부 필수 | 조직에서 처음 관리하는 의약품의 최대 허용 습도   |
| 최소 조도 | Decimal | 조건부 필수 | 조직에서 처음 관리하는 의약품의 최소 허용 조도   |
| 최대 조도 | Decimal | 조건부 필수 | 조직에서 처음 관리하는 의약품의 최대 허용 조도   |
| 메모  | String  |   선택   | 입고 처리와 관련된 추가 설명             |



## 처리 절차

1. 전달받은 입고 정보의 필수값과 입력 형식을 검증한다.
2. 현재 로그인한 사용자의 조직 소속 상태와 입고 등록 권한을 확인한다.
3. 선택한 의약품이 내부 의약품 데이터베이스에 존재하는지 확인한다.
4. 선택한 저장소가 사용자의 조직에 속하며 사용 가능한 상태인지 확인한다.
5. 선택한 보관 구역이 해당 저장소에 속하며 사용 가능한 상태인지 확인한다.
6. 보관 구역의 최신 온도·습도·조도 관리 범위가 의약품 환경 기준을 충족하는지 확인한다.
7. 해당 의약품이 현재 조직의 관리 의약품으로 등록되어 있는지 확인한다.
8. 조직에서 처음 관리하는 의약품이면 조직 관리 의약품 정보와 입력된 환경 기준을 저장한다.
9. 기존 관리 의약품의 환경 기준이 변경된 경우 사용자의 수정 권한을 확인한 후 변경된 값을 반영한다.
10. 데이터베이스 트랜잭션을 시작한다.
11. 시스템은 다음 조건을 기준으로 동일 재고가 존재하는지 조회한다.
    - 조직 ID
    - 의약품 ID
    - 제조번호
    - 실제 유통기한
    - 저장소 ID
    - 보관 구역 ID
12. 동일 재고가 존재하지 않으면 신규 재고를 생성한다.
13. 신규 재고에는 의약품, 저장소, 보관 구역, 제조번호, 실제 유통기한 및 현재 수량을 저장한다.
14. 신규 재고의 현재 수량은 입력된 입고 수량으로 설정한다.
15. 신규 재고의 입고 전 수량은 0, 입고 후 수량은 입력된 입고 수량으로 설정한다.
16. 신규 재고의 초기 상태는 `NORMAL`로 설정한다.
17. 동일 재고가 존재하면 기존 재고의 현재 수량을 조회한다.
18. 시스템은 기존 현재 수량에 입고 수량을 더하여 입고 후 수량을 계산한다.
19. 계산된 입고 후 수량으로 기존 재고의 현재 수량을 갱신한다.
20. 거래 유형이 `INBOUND`인 재고 변동 내역을 생성한다.
21. 재고 생성 또는 수량 갱신과 재고 변동 내역 저장이 모두 성공하면 트랜잭션을 커밋한다.
22. 저장 과정에서 오류가 발생하면 재고와 변동 내역에 반영된 변경 내용을 모두 롤백한다.
23. 입고 완료 후 시스템은 해당 저장소와 의약품을 기준으로 출고 가능 수량을 다시 계산한다.
24. 시스템은 해당 저장소와 의약품에 재고 부족 알림이 설정되어 있는지 확인한다.
25. 재고 부족 알림이 설정되어 있으면 출고 가능 수량과 기준 수량을 비교한다.
26. 입고로 출고 가능 수량이 기준 수량을 초과하면 기존 재고 부족 알림을 해결 상태로 변경한다.
27. 시스템은 입고 등록 성공 결과를 반환한다.
28. 시스템은 입고 등록이 완료되었습니다. 메시지를 표시하고 전체 재고 목록으로 이동시킨다.



## 업무 규칙

- 동일 재고는 다음 항목이 모두 같은 경우로 판단한다.
    - 조직
    - 의약품 
    - 제조번호 
    - 실제 유통기한 
    - 저장소
    - 보관 구역
- 동일 재고가 존재하면 신규 재고를 생성하지 않고 기존 재고 수량에 입고 수량을 합산한다.
- 동일 재고 조건 중 하나라도 다르면 별도의 신규 재고로 생성한다.
- 제조번호는 앞뒤 공백을 제거한 후 저장한다.
- 제조번호는 공백으로만 구성될 수 없다.
- 실제 유통기한은 실제 제품 포장에 표시된 날짜를 저장한다.
- 실제 유통기한은 현재 날짜 이후여야 한다.
- 입고 수량은 1 이상의 정수여야 한다.
-  신규 재고의 입고 전 수량은 0으로 처리한다.
-  입고 후 수량은 입고 전 수량 + 입고 수량으로 계산한다.
-  신규 재고의 초기 상태는 NORMAL로 설정한다.
- 조직 관리 의약품은 조직 ID + 의약품 ID 조합으로 중복 생성할 수 없다.
-  의약품 환경 기준은 제조번호나 유통기한별로 저장하지 않고 조직 ID + 의약품 ID 단위로 관리한다.
-  기존 의약품 환경 기준은 환경 기준 수정 권한이 있는 사용자만 변경할 수 있다.
-  재고 수량 저장과 INBOUND 변동 내역 저장은 하나의 트랜잭션으로 처리한다.
-  재고 수량 저장 또는 변동 내역 저장 중 하나라도 실패하면 입고 처리 전체를 롤백한다.
-  처리 담당자와 처리 일시는 사용자가 직접 입력하거나 수정할 수 없다.
-  처리 담당자는 현재 로그인한 사용자로 기록한다.
-  처리 일시는 서버 시간을 기준으로 기록한다.
-  완료된 입고 변동 내역은 직접 수정하지 않는다.
-  잘못 등록한 입고 내역은 기존 내역을 수정하지 않고 입고 취소 기능을 통해 반대 변동 내역을 생성하여 처리한다.
-  입고 등록에서는 유통기한 임박 알림 사용 여부나 임박 기준일을 설정하지 않는다.
-  입고 등록에서는 재고 부족 기준 수량을 설정하지 않는다.
-  재고 부족 상태는 저장소 ID + 의약품 ID 단위의 출고 가능 수량을 기준으로 다시 판단한다.
-  재고 부족 알림이 설정되지 않은 저장소와 의약품은 알림 상태를 갱신하지 않는다.



## 처리 결과

- 조직에서 처음 관리하는 의약품이면 조직 관리 의약품 정보가 생성된다.
- 조직에서 처음 관리하는 의약품의 환경 기준이 저장된다.
- 수정 권한을 가진 사용자가 기존 환경 기준을 변경한 경우 변경된 값이 반영된다.
- 동일 재고가 없으면 신규 재고가 생성된다.
- 신규 재고의 현재 수량은 입력한 입고 수량으로 저장된다.
- 신규 재고의 초기 상태는 NORMAL로 저장된다.
- 동일 재고가 있으면 기존 재고의 현재 수량에 입고 수량이 합산된다.
- 입고 전 수량과 입고 후 수량이 계산된다.
- 거래 유형이 INBOUND인 재고 변동 내역이 생성된다.
- 변동 내역에 입고 수량, 입고 전 수량, 입고 후 수량, 처리 담당자, 처리 일시 및 메모가 저장된다.
- 입고 후 해당 저장소의 의약품 출고 가능 수량이 다시 계산된다.
- 입고로 재고 부족 상태가 해소된 경우 기존 재고 부족 알림이 해결 상태로 변경된다.
- 저장된 재고는 전체 재고 목록과 재고 상세 화면에서 조회할 수 있다.
- 입고 처리 내역은 재고 변동 내역 화면에서 조회할 수 있다.
- 사용자에게 입고 등록이 완료되었습니다. 메시지를 반환한다.

| 보관 구역을 선택하지 않음                         | 실제 입고할 보관 구역을 선택하도록 안내하고 입고 처리를 중단한다.                   |
| 선택한 보관 구역이 해당 저장소에 속하지 않음              | 올바른 보관 구역을 다시 선택하도록 안내하고 입고 처리를 중단한다.                   |
| 선택한 보관 구역이 사용 불가 상태임                   | 사용 가능한 보관 구역을 다시 선택하도록 안내한다.                            |
| 보관 구역의 최신 환경 관리 범위가 의약품 환경 기준을 충족하지 않음 | 해당 보관 구역에 입고할 수 없음을 안내하고 다른 구역을 선택하도록 한다.               |
| 조직에서 처음 관리하는 의약품의 환경 기준이 입력되지 않음       | 의약품 환경 기준을 입력하도록 안내하고 입고 처리를 중단한다.                      |
| 기존 의약품의 환경 기준을 수정할 권한이 없음              | 환경 기준 변경 요청을 거부하고 기존 기준을 유지한다.                          |
| 제조번호가 입력되지 않거나 공백으로만 구성됨               | 제조번호를 입력하도록 안내하고 입고 처리를 중단한다.                           |
| 실제 유통기한이 입력되지 않음                       | 실제 유통기한을 입력하도록 안내하고 입고 처리를 중단한다.                        |
| 실제 유통기한의 형식이 올바르지 않음                   | 올바른 날짜 형식으로 다시 입력하도록 안내한다.                              |
| 실제 유통기한이 현재 날짜 이전이거나 현재 날짜와 같음         | 현재 날짜 이후의 유통기한을 입력하도록 안내하고 입고 처리를 중단한다.                 |
| 입고 수량이 입력되지 않음                         | 입고 수량을 입력하도록 안내하고 입고 처리를 중단한다.                          |
| 입고 수량이 정수가 아니거나 1 미만임                  | 1 이상의 정수를 입력하도록 안내하고 입고 처리를 중단한다.                       |
| 메모가 허용된 최대 길이를 초과함                     | 허용된 글자 수 이내로 수정하도록 안내한다.                                |
| 조직 관리 의약품 정보 저장에 실패함                   | 현재 입고 처리를 롤백하고 입고 등록 실패 메시지를 표시한다.                      |
| 의약품 환경 기준 저장 또는 변경에 실패함                | 현재 입고 처리를 롤백하고 기존 환경 기준을 유지한다.                          |
| 동일 재고 조회 중 데이터베이스 오류가 발생함              | 입고 처리를 중단하고 일시적인 오류 메시지를 표시한다.                          |

| 기존 재고 수량 갱신에 실패함                       | 현재 트랜잭션을 롤백하고 기존 재고 수량을 유지한다.                           |
