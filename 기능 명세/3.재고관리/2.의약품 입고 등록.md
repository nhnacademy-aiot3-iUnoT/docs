# 📝 2. 의약품 입고 등록

## 기능 목적

> 입고된 의약품을 제조번호, 실제 유통기한 및 보관 위치별로 구분하여 재고를 정확하게 관리하기 위한 기능이다.
> 입고에 따른 재고 수량 변동과 처리 담당자 이력을 자동으로 기록하여 재고 변경 근거를 추적할 수 있도록 한다.

## 사용자 및 권한

- 로그인한 사용자만 이용할 수 있다. 
- 다음 사용자만의 의약품 입고를 등록할 수 있다.
    - 조직 소유자 `OWNER`
    - 재고 관리 권한을 부여받은 `MEMBER`
- 사용자는 자신이 소속된 조직의 저장소에만 입고를 등록할 수 있다. 
- 권한이 없는 사용자는 입고 등록 화면에 접근할 수 없다. 
- 기존 의약품의 환경 기준 수정은 환경 기준 수정 권한을 가진 사용자만 가능하다.


## 사전 조건

- 사용자가 로그인된 상태여야 한다.
- 사용자에게 입고 등록 권한이 있어야 한다.
- 의약품 공공데이터가 시스템의 의약품 정보 데이터베이스에 저장되어 있어야 한다.
- 조직에 사용 가능한 저장소가 등록되어 있어야 한다.
- 선택한 저장소에 사용 가능한 보관 구역이 등록되어 있어야 한다. 
- 선택한 보관 구역에 온도, 습도, 조도 등의 환경 기준이 설정되어 있어야 한다.
- 입고 대상 의약품이 조직에서 처음 관리되는 의약품인 경우, 입고 과정에서 조직 관리 의약품으로 등록할 수 있어야 한다.




## 입력값

### 의약품 검색

| 항목     | 형식  | 필수 여부 | 설명                        |
| ------ | --- | :---: | ------------------------- |
| 검색어    | 문자열 |   필수  | 제품명 또는 품목기준코드를 입력한다.      |
| 의약품 선택 | 선택값 |   필수  | 검색 결과에서 실제 입고할 의약품을 선택한다. |


### 의약품 자동 조회 정보 

| 항목       | 공공데이터 필드         | 형식  | 필수 여부 | 설명                             |
| -------- | ---------------- | --- | :---: | ------------------------------ |
| 품목기준코드   | `ITEM_SEQ`       | 문자열 |   자동  | 공공데이터에서 의약품을 식별하는 코드이다.        |
| 제품명      | `ITEM_NAME`      | 문자열 |   자동  | 의약품 제품명이다.                     |
| 업체명      | `ENTP_NAME`      | 문자열 |   자동  | 의약품 제조 또는 수입 업체명이다.            |
| 저장방법     | `STORAGE_METHOD` | 문자열 |   자동  | 저장소 및 보관 구역 선택 시 참고하는 보관 정보이다. |
| 허가된 유효기간 | `VALID_TERM`     | 문자열 |   자동  | 제조일을 기준으로 허가된 사용 가능 기간이다.      |
| 성분·함량 정보 | `MATERIAL_NAME`  | 문자열 |   자동  | 의약품의 주요 성분 및 함량 정보이다.          |


- 자동 조회된 의약품 정보는 사용자가 수정할 수 없다.
- 저장 방법은 환경 기준 설정을 위한 참고 정보로만 표시한다.



### 실제 입고 정보

| 항목      | 형식    | 필수 여부 | 설명                                   |
| ------- | ----- | :---: | ------------------------------------ |
| 제조번호    | 문자열   |   필수  | 실제 제품에 표시된 제조번호 또는 LOT 번호를 입력한다.     |
| 실제 유통기한 | 날짜    |   필수  | 실제 제품 포장에 표시된 유통기한을 입력한다.            |
| 입고 수량   | 양의 정수 |   필수  | 실제 입고되는 의약품 수량을 입력한다.                |
| 저장소     | 선택값   |   필수  | 사용자가 소속된 조직의 사용 가능한 저장소 중 하나를 선택한다.  |
| 보관 구역   | 선택값   |   필수  | 선택한 저장소에 속한 사용 가능한 보관 구역 중 하나를 선택한다. |
| 메모      | 문자열   |   선택  | 입고와 관련된 추가 내용을 입력한다.                 |


### 유통기한 임박 알림 설정
| 항목             | 형식       |    필수 여부   | 설명                                        |
|----------------| -------- | :--------: | ----------------------------------------- |
| 유통기한 임박 알림 사용 여부 | 불리언      | 최초 등록 시 필수 | 해당 의약품의 유통기한 임박 알림을 사용할지 선택한다.            |
| 유통기한 임박 기준일    | 1 이상의 정수 |   조건부 필수   | 알림 사용을 선택한 경우 유통기한 며칠 전부터 임박으로 판단할지 입력한다. |

- 알림 `사용`을 선택하면 기준일 입력란을 활성화한다.
- 알림 `사용 안 함`을 선택하면 기준일 입력란을 비활성화한다.
- 알림 `사용 안 함`인 경우 기준일은 `null`로 처리한다.
- 기존 등록 의약품은 저장된 알림 설정을 자동으로 불러온다.
- 기존 알림 설정은 수정이 가능하다.


### 의약품 환경 기준

| 항목            | 형식       |    필수 여부   | 설명                                           |
| ------------- | -------- | :--------: | -------------------------------------------- |
| 최소 온도         | 숫자       | 필수 | 의약품의 허용 가능한 최소 온도를 입력한다.                     |
| 최대 온도         | 숫자       | 필수 | 의약품의 허용 가능한 최대 온도를 입력한다.                     |
| 최소 습도         | 숫자       | 필수 | 의약품의 허용 가능한 최소 습도를 입력한다.                     |
| 최대 습도         | 숫자       | 필수 | 의약품의 허용 가능한 최대 습도를 입력한다.                     |
| 최소 조도         | 숫자       |     선택     | 의약품의 허용 가능한 최소 조도를 입력한다.                     |
| 최대 조도         | 숫자       | 필수 | 의약품의 허용 가능한 최대 조도를 입력한다.                     |

- 조직에서 처음 등록하는 의약품은 사용자가 공공데이터의 저장방법을 참고하여 환경 기준을 입력한다.
- 기존 등록 의약품은 저장된 환경 기준을 자동으로 불러온다.
- 입고 등록 권한이 있는 사용자는 기존 의약품 환경 기준을 수정할 수 있다.
- 문 열림 감지 여부와 문 열림 허용 시간은 의약품 환경 기준에 포함하지 않는다.



### 저장 위치

| 항목    | 형식  | 필수 여부 | 설명                                         |
| ----- | --- | :---: | ------------------------------------------ |
| 저장소   | 선택값 |   필수  | 사용자가 소속된 조직의 사용 가능한 저장소 중 하나를 선택한다.        |
| 보관 구역 | 선택값 |   필수  | 선택한 저장소 안에서 의약품 환경 기준을 충족하는 구역 중 하나를 선택한다. |

- 의약품 환경 기준이 설정되거나 기준 기준이 조회된 이후 저장소를 선택할 수 있다.
- 저장소를 선택하면 시스템은 해당 저장소에 속한 보관 구역의 환경 임계치를 조회한다.
- 시스템은 온도, 습도 및 조도 기준을 충족하는 보관 구역만 선택 가능하게 제공한다.
- 문 열림 임계치는 보관 구역 선택을 위한 의약품 적합성 판정 조건에 포함하지 않는다.

## 보관 구역 적합성 판정
보관 구역의 환경 관리 범위가 의약품의 허용 범위 안에 포함되어야 한다.


### 온도 

#### 적합한 경우
의약품이 허용하는 온도가 1~30℃이고, 구역이 5~25℃로 관리된다면:
```
의약품 허용 범위: 1 ─────────────── 30
구역 관리 범위:       5 ─────── 25
```
#### 부적합한 경우
의약품이 냉장 상태인 2~8℃만 허용하는데, 구역이 1~30℃로 관리된다면:

```
의약품 허용 범위:   2 ─── 8
구역 관리 범위:   1 ─────────────── 30
```
의약품 허용 범위보다 구역 관리 범위가 좁고 그 안에 들어와야 함.



### 습도

```
의약품 최소 습도 ≤ 구역 최소 습도
구역 최대 습도 ≤ 의약품 최대 습도
```

### 조도 
최소 조도를 설정한 경우:
```
의약품 최소 조도 ≤ 구역 최소 조도
구역 최대 조도 ≤ 의약품 최대 조도
```
최소 조도를 설정하지 않은 경우:
```
구역 최대 조도 ≤ 의약품 최대 조도
```
- 온도,습도 또는 조도 중 하나라도 기준을 충족하지 않으면 해당 보관 구역은 선택할 수 없다.
- 문 열림 임계치는 구역 운영 기준이므로 위 적합성 판정에 포함하지 않는다.



## 동일 재고 판정 기준
다음 조건이 모두 동일한 경우 동일 재고로 판단한다.
- 동일 조직
- 동일 의약품
- 동일 제조번호
- 동일 실제 유통기한
- 동일 저장소
- 동일 보관 구역

동일 재고가 존재하면 신규 재고를 생성하지 않고 기존 재고 수량에 입고 수량을 합산한다.

다음 중 하나라도 다르면 별도 재고로 생성한다.
- 재조 번호
- 실제 유통기한
- 저장소
- 보관 구역

## 처리 절차

1. 사용자가 전체 재고 목록 상단의 `입고 등록` 버튼을 선택한다.
2. 시스템은 사용자의 로그인 상태와 입고 등록 권한을 확인한다.
3. 사용자가 제품명 또는 품목기준코드로 의약품을 검색한다.
4. 시스템은 내부 의약품 데이터베이스에서 검색 조건과 일치하는 의약품을 조회한다. 
5. 사용자가 검색 결과에서 입고할 의약품을 선택한다.
6. 시스템은 다음 의약품 정보를 자동으로 표시한다. 
      - 품목기준코드
      - 제품명
      - 업체명
      - 저장방법
      - 허가된 유효기간
      - 성분·함량 정보
7. 시스템은 해당 의약품이 현재 조직에서 관리 중인 의약품인지 확인한다.
8. 처음 등록하는 의약품이면 유통기한 임박 알림 설정과 의약품 환경 기준 입력란을 활성화한다.
9. 기존 등록 의약품이면 유통기한 임박 알림설정과 환경 기준을 자동으로 불러온다. 다른 값으로 수정도 가능하다.
10. 사용자는 유통기한 임박 알림 사용 여부를 선택한다.
11. 알림을 사용하는 경우 유통기한 임박 기준일을 입력한다.
12. 사용자는 공공데이터의 저장방법을 참고하여 온도, 습도 및 조도 기준을 설정하거나 기존 기준을 확인·수정한다.
13. 시스템은 환경 기준과 알림 설정의 입력값을 검증한다.
14. 사용자가 입고할 저장소를 선택한다.
15. 시스템은 선택한 저장소에 속한 사용 가능한 보관 구역을 조회한다.
16. 시스템은 각 보관 구역의 온도, 습도 및 조도 임계치를 의약품 환경 기준과 비교한다.
17. 시스템은 의약품 환경 기준을 충족하는 보관 구역만 선택 가능하게 표시한다.
18. 사용자가 실제 입고할 보관 구역을 선택한다.
19. 사용자는 제조번호, 실제 유통기한, 입고 수량 및 메모를 입력한다.
20. 사용자가 `입고 등록` 버튼을 선택한다.
21. 시스템은 다음 내용을 최종 검증한다.
      - 사용자 권한
      - 입력값
      - 저장소 상태
      - 보관 구역 상태
      - 보관 구역 환경 기준 적합성 
22. 시스템은 동일 재고가 기존에 존재하는지 확인한다.
23. 조직에서 처음 관리하는 의약품이면 조직 관리 의약품 정보, 환경 기준 및 유통기한 임박 알림 설정을 생성한다.
24. 기존 등록 의약품의 환경 기준 또는 알림 설정이 변경된 경우 변경 내용을 반영한다.
25. 동일 재고가 없으면 신규 재고를 생성한다.
26. 동일 재고가 있으면 기존 재고 수량에 입고 수량을 합산한다.
27. 시스템은 입고 전 수량, 입고 수량 및 입고 후 수량을 계산한다.
28. 시스템은 거래 유형이 INBOUND인 재고 변동 내역을 생성한다.
29. 시스템은 현재 로그인한 사용자를 처리 담당자로 기록한다.
30. 시스템은 서버 처리 완료 시각을 처리 일시로 기록한다.
31. 시스템은 입고 후 유통기한 임박 여부를 다시 계산한다.
32. 시스템은 입고 후 저장소별 재고 부족 여부를 다시 계산한다.
33. 모든 처리가 완료되면 사용자에게 입고 완료 결과를 표시한다.


## 요구사항

 ### 1.1 의약품 검색 및 조회
- [ ] 사용자는 전체 재고 목록 상단의 입고 등록 버튼을 통해 입고 등록 화면으로 이동할 수 있어야 한다.
- [ ] 사용자는 제품명 또는 품목기준코드로 입고할 의약품을 검색할 수 있어야 한다.
- [ ] 시스템은 외부 공공데이터 API를 직접 호출하지 않고 내부 의약품 데이터베이스에서 검색해야 한다.
- [ ] 사용자는 검색 결과에서 입고할 의약품을 선택할 수 있어야 한다.
- [ ] 시스템은 선택한 의약품의 다음 정보를 자동으로 표시해야 한다.
  - 품목기준코드
  - 제품명
  - 업체명
  - 저장방법
  - 허가된 유효기간
  - 성분·함량 정보
- [ ] 자동 조회된 의약품 정보는 사용자가 직접 수정할 수 없어야 한다.
- [ ] 저장방법은 의약품 환경 기준을 설정하기 위한 참고 정보로 표시해야 한다.

 ### 1.2 조직 관리 의약품 확인

- [ ] 시스템은 선택한 의약품이 현재 조직에서 관리 중인 의약품인지 확인해야 한다.
- [ ] 해당 조직에서 처음 입고하는 의약품은 입고 과정에서 조직 관리 의약품으로 등록할 수 있어야 한다.
- [ ] 기존 등록 의약품은 저장된 환경 기준과 유통기한 임박 알림 설정을 자동으로 불러와야 한다.

 ### 1.3 유통기한 임박 알림 설정
- [ ] 사용자는 유통기한 임박 알림 사용 여부를 선택할 수 있어야 한다.
- [ ] 알림 사용을 선택한 경우 유통기한 임박 기준일을 입력할 수 있어야 한다.
- [ ] 알림 사용 안 함을 선택한 경우 기준일 입력란을 비활성화하거나 숨겨야 한다.
- [ ] 기존 등록 의약품은 저장된 알림 사용 여부와 기준일을 자동으로 표시해야 한다.
- [ ] 입고 등록 권한이 있는 사용자는 기존 알림 설정을 변경할 수 있어야 한다.


 ### 1.4 의약품 환경 기준 설정

- [ ] 사용자는 공공데이터의 저장방법을 참고하여 다음 환경 기준을 설정할 수 있어야 한다.
  - 최소 온도
  - 최대 온도
  - 최소 습도
  - 최대 습도
  - 최소 조도
  - 최대 조도

- [ ] 최소 조도는 선택적으로 입력할 수 있어야 한다.
- [ ] 조직에서 처음 관리하는 의약품은 환경 기준을 새로 설정할 수 있어야 한다.
- [ ] 기존 등록 의약품은 저장된 환경 기준을 자동으로 표시해야 한다.
- [ ] 입고 등록 권한이 있는 사용자는 기존 의약품 환경 기준을 변경할 수 있어야 한다.
- [ ] 환경 기준은 제조번호나 유통기한별이 아닌 조직과 의약품의 조합별로 관리해야 한다.
- [ ] 문 열림 감지 여부와 허용 시간은 의약품 환경 기준에 포함하지 않아야 한다. 

  ### 1.5 저장소 및 보관 구역 선택

- [ ] 의약품 환경 기준이 설정되거나 기존 기준이 조회된 이후 저장소를 선택할 수 있어야 한다.
- [ ] 사용자는 자신이 소속된 조직의 사용 가능한 저장소만 선택할 수 있어야 한다.
- [ ] 저장소 선택 시 시스템은 해당 저장소에 속한 사용 가능한 보관 구역을 조회해야 한다.
