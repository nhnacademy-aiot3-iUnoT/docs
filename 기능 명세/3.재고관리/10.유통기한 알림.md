# 📝 10.1 유통기한 임박 의약품 데이터 자동 갱신

## 기능 목적

> 전체 재고 데이터 중 유통기한이 14(기준)일 이하로 남은 의약품을 필터링 하여 임박 알림 테이블에 저장

## 사용자 및 권한

- 시스템(재고관리 서비스)

## 사전 조건

- 매일 00:00:00(또는 시스템 부하가 적은 시간대)에 스케쥴러를 통해 갱신 프로세스 가동


## 처리 절차

1. 기존 테이블 전체 데이터 삭제
2. 재고 데이터
3. 
4. 

## 입력값

| 항목   | 형식      | 필수 여부 | 설명        |
|------|---------|:-----:|-----------|
| 제품명  | String  |   Y   | 대상 제품의 이름 |
| 저장소  | String  |   Y   | 재고 위치 정보  |
| 최소수량 | Integer |   Y   | 재고 최소 수량  |

## 업무 규칙

- 최소 수량이 유효한 값인지 검증한다(마이너스 방지)

## 처리 결과

- 성공 시: 최소 재고 품목 저장
- 실패 시: error Api Response 반환
