# 📝 3.7 환경 이상 재고 검토

## 기능 목적

>의약품 보관 환경의 온도가 적정 온도 범위를 벗어난 경우, 해당 보관 위치에 있는 의약품 목록을 검토대상으로 제공하고 사용자가 현장 확인 후 폐기 필요 여부를 판단할 수 있도록 지원하는 것을 목적으로 한다.
> 이를 통해 온도 이탈로 인해 품질 저하 가능성이 있는 의약품을 식별하고, 폐기 대상 의약품을 폐기 대기 상태로 전환하여 의약품 관리의 안정성과 추적성을 확보할 수 있다.


## 사용자 및 권한

- 해당 조직의 `OWNER`또는 재고관리 권한이 `ACTIVE`된 사용자



## 사전 조건

- 보관 위치별 적정 환경 범위가 설정되어 있어야 한다.
- 보관 환경 측정값이 시스템에 수집되어야 한다.
- 환경 센서 또는 환경 기록이 보관 위치와 연결되어 있어야 한다.
- 의약품이 이벤트 발생 위치 기준으로 관리되고 있어야 한다.
- 해당 위치에 현재 재고가 존재해야 검토 대상 목록이 생성된다.
- 환경 이상 알림이 발생한 상태여야 검토 기능을 사용할 수 있다.
- 사용자는 해당 조직 내 재고 관리 권한을 부여받은 상태여야 한다.



## 입력값

| 항목    | 형식 | 필수 여부 | 설명                 |
|-------|----|:-----:|--------------------|
| 센서 로그 |    |   Y   | 환경 이상 이벤트 번호       |
| 재고 수량 |    |   Y   | 폐기 대기 상태로 전환할 재고   |
| 로트 번호 |    |   Y   | 폐기 대기 대상 의약품 로트 번호 |
| 임시저장  |    |   Y   | 임시저장 여부            |



## 처리 절차

1. 환경 설정된 적정 기준에서 이탈이 감지되면서 환경 이상 이벤트와 연결된다. 
2. 이벤트가 발생한 보관 위치를 기준으로 해당 위치의 의약품 재고 목록을 검토 대상으로 생성한다. 
3. 환경 이상 재고 검토 화면이 생성된다. 
4. 해당 위치에 보관된 재고들은 `HOLD`상태로 자동 변경되어 출고/이동하지 못하게 한다. 
5. 사용자가 검토 목록에서 선택한 폐기할 의약품만 폐기 대기 상태로 변경된다.
6. 폐기 대상을 폐기 프로세스로 이관한다. 
7. 미선택 재고들은 `HOLD`상태에서 정상 재고로 복구된다.
7. 검토 결과와 처리 이력을 저장한다. 
8. 처리 완료 결과를 사용자에게 표시한다.


## 규칙 및 요구사항

1. - [ ] 환경관리 모듈로부터 수신한 ID를 기준으로 해당 위치에 있던 의약품을 검토 대상으로 조회할 수 있어야 한다.
2. - [ ] 검토 대상은 환경 이상의 발생 시각부터 종료 시각 사이에 해당 위치에 압고되어 있었던 모든 재고 로트번호를 정확히 추출해야 한다.
3. - [ ] 검토 대상 화면에는 의약품명, 로트번호, 유통기한, 보관위치, 현재고 수량이 함께 표시되어야 한다.
4. - [ ] 체크박스를 클릭하는 것 외에 바코드 또는 RFID를 직접 스캔하여 재고를 검토 처리할 수 있는 기능을 선택적으로 사용할 수 있어야 한다.
5. - [ ] 동일한 로트번호의 의약품이라도 일부 수량만 분할 지정할 수 있어야 한다.
6. - [ ] 검토내역을 `임시저장`할 수 있어야 한다.
7. - [ ] `임시저장`한 후 이어서 검토할 수 있어야 한다.
8. - [ ] 검토 목록이 생성된 순간부터 해당 의약품들은 자동 `HOLD` 상태로 변경되어야 한다.
9. - [ ] 페기 대기( `PEN_DISP`)로 지정된 의약품은 일반 재고 수량에서 차감되지 않으나, 출고 가능 재고 수량에선 제외되어야 한다.
10. - [ ] 사용자가 체크하지 않은 의약품은 검토 완료를 버튼을 누르는 즉시 `HOLD`상태가 해제되어 `NORMAL`로 자동 환원되어야 한다.
11. - [ ] 폐기 승인 및 처리 기능으로 데이터가 자동 이관되어야 한다.
12. - [ ] 폐기 대기 상태의 의약품은 최종 폐기가 승인 되어야만 실제 보유 재고 수량에서 차감 되어야 한다.
13. - [ ] 폐기 대기 상태의 의약품을 정상 복구할 때는 해당 건을 처리를 한 담당자와 오너만 처리할 수 있어야 한다.
14. - [ ] 일정시간 동안 환경이상 이벤트에 대한 검토완료 처리가 되지 않고 `검토 대기`/`임시 저장` 상태로 유지될 경우, 담당자 및 관리자에게 미완료 알림을 발송해야 한다.
15. - [ ] 마약류 또는 지정 전문의약품의 경우 이중 검토자 단계가 추가로 활성될 수 있어야 한다.


## 처리 결과

- 사용자가 선택한 의약품은 `PEND_DISP`상태로 변경된다.
- 사용자가 미선택한 의약품은 `HOLD`상태에서  `NORMAL`상태로 자동 전환된다.
