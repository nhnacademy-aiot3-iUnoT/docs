# 📝 4. 의약품 상세 조회

## 기능 목적

> 전체 재고 목록에서 선택한 의약품의 저장소 내 세부 재고 정보를 조회하기 위한 기능이다.
> 동일한 의약품이 보관 구역, 제조번호 및 실제 유통기한에 따라 여러 재고로 나뉘어 있는 경우
> 각 재고의 현재 수량, 재고 상태 및 환경 검토 정보를 확인할 수 있도록 한다.


## 사용자 및 권한

- 로그인한 사용자인 조직 소유자 `OWNER`또는 재고 관리 권한을 부여받은 `MEMBER`만 의약품 재고 상세 정보를 조회할 수 있다.
- 사용자는 자신이 현재 소속된 조직의 재고만 조회할 수 있다.
- 다른 조직의 의약품 재고 상세 정보는 조회할 수 없다.
- 권한이 없는 사용자는 재고 상세 화면에 접근할 수 없다.


## 사전 조건

- 사용자가 현재 조직에 정상적으로 소속되어 있어야 한다.
- 사용자에게 재고 조회 권한이 있어야 한다.
- 사용자가 전체 재고 목록에서 조회할 의약품의 상세보기를 선택한 상태여야 한다.
- 선택한 의약품과 저장소가 현재 조직에 속한 재고 정보와 연결되어 있어야 한다.
- 의약품, 저장소, 보관 구역 및 재고 정보가 데이터베이스에 저장되어 있어야 한다.



## 입력값

| 항목  | 형식  | 필수 여부 | 설명                               |
| --- | --- | :---: | -------------------------------- |
| 의약품 | 선택값 |   필수  | 전체 재고 목록에서 상세 조회 대상으로 선택한 의약품이다. |
| 저장소 | 선택값 |   필수  | 선택한 의약품 재고가 보관된 상세 조회 대상 저장소이다.  |


## 조회 데이터

| 데이터      | 조회 목적                                      |
| -------- | ------------------------------------------ |
| 의약품 정보   | 선택한 재고에 연결된 제품명, 업체명 및 품목기준코드를 조회한다.       |
| 저장소 정보   | 상세 조회 대상 저장소명을 조회한다.                       |
| 보관 구역 정보 | 각 재고가 실제로 보관된 보관 구역명을 조회한다.                |
| 재고 정보    | 제조번호, 실제 유통기한, 현재 수량 및 재고 상태를 조회한다.        |
| 환경 검토 정보 | 환경 이상 발생으로 해당 재고가 검토 대상인지와 검토 진행 상태를 조회한다. |
| 환경 이상 정보 | 환경 검토가 발생한 원인과 관련된 온도·습도·조도 이상 항목을 조회한다.   |



## 처리 절차

1. 현재 로그인한 사용자의 조직 소속 상태와 재고 조회 권한을 확인한다.
2. 전체 재고 목록에서 선택된 의약품과 저장소 정보를 확인한다.
3. 선택한 의약품이 내부 의약품 정보 데이터베이스에 존재하는지 확인한다.
4. 선택한 저장소가 현재 사용자의 조직에 속하는지 확인한다.
5. 재고 데이터베이스에서 다음 조건을 만족하는 재고 정보를 조회한다. 
   - 현재 사용자의 조직에 속한 재고
   - 선택한 의약품에 해당하는 재고 
   - 선택한 저장소에 보관된 재고
9. 시스템은 조회된 각 재고에 연결된 보관 구역 정보를 조회한다.
10. 시스템은 각 재고의 제조번호, 실제 유통기한, 현재 수량 및 재고 상태를 조회한다.
11. 시스템은 각 재고에 연결된 환경 검토 정보가 존재하는지 확인한다.
12. 환경 검토 정보가 존재하면 검토 상태, 검토 대상이 된 환경 항목 및 관련 정보를 조회한다.
13. 환경 검토 정보가 존재하지 않으면 해당 재고의 환경 검토 상태를 해당 없음으로 처리한다.
14. 시스템은 조회된 재고를 보관 구역, 제조번호 및 실제 유통기한별로 구분한다.
15. 시스템은 의약품 기본 정보와 저장소 정보를 상세 화면 상단에 표시한다.
16. 시스템은 보관 구역, 제조번호, 실제 유통기한, 현재 수량, 재고 상태 및 환경 검토 정보를 재고 상세 목록으로 반환한다.
17. 현재 수량이 남아 있는 재고를 기본 상세 목록에 표시한다.
18. 소진 또는 폐기 완료된 재고는 기본 상세 목록에서 제외한다.


## 의약품 기본 정보

| 항목     | 설명                           |
| ------ | ---------------------------- |
| 제품명    | 선택한 의약품의 제품명을 표시한다.          |
| 업체명    | 선택한 의약품의 제조 또는 수입 업체명을 표시한다. |
| 품목기준코드 | 선택한 의약품을 식별하는 품목기준코드를 표시한다.  |
| 저장소    | 현재 상세 조회 중인 저장소명을 표시한다.      |


## 재고 상세 목록

| 항목       | 설명                                                |
| -------- | ------------------------------------------------- |
| 보관 구역    | 해당 재고가 실제 보관된 구역명을 표시한다.                          |
| 제조번호     | 실제 입고된 의약품의 제조번호 또는 LOT 번호를 표시한다.                 |
| 실제 유통기한  | 실제 제품 포장에 표시된 유통기한을 표시한다.                         |
| 현재 수량    | 해당 제조번호와 유통기한을 가진 재고의 현재 수량을 표시한다.                |
| 재고 상태    | 정상, 만료, 검토 중, 폐기 완료 등의 상태를 표시한다.       |
| 환경 검토 정보 | 해당 없음, 검토 중, 검토 완료 등의 환경 검토 상태와 검토 대상 환경 항목을 표시한다. |






## 업무 규칙

- 의약품 재고 상세 조회는 현재 로그인한 사용자가 소속된 조직을 기준으로 수행한다.
- 다른 조직에 속한 재고는 조회 결과에 포함하지 않는다.
- 상세 조회 대상은 전체 재고 목록에서 선택한 의약품 + 저장소 조합으로 한다.
- 상세 화면에서는 동일한 의약품 재고를 보관 구역, 제조번호 및 실제 유통기한별로 구분하여 표시한다.
- 제조번호, 실제 유통기한, 저장소 또는 보관 구역 중 하나라도 다르면 별도의 재고로 표시한다.
- 현재 수량은 해당 개별 재고에 저장된 조회 시점의 수량을 표시한다.
- 재고 상태는 개별 재고를 기준으로 표시한다.
- 유통기한 임박 및 만료 상태는 실제 유통기한을 기준으로 판단한다.
- 환경 이상으로 검토가 진행 중인 재고는 재고 상태에 검토 중을 표시한다.
- 환경 검토 상태와 유통기한 상태는 동시에 존재할 수 있다.
- 여러 상태가 동시에 존재하면 하나의 상태로 덮어쓰지 않고 복수 상태로 표시할 수 있다.
- 환경 검토 정보가 존재하지 않는 재고는 환경 검토 상태를 해당 없음으로 표시한다.
- 환경 검토가 완료된 재고는 검토 결과에 따라 정상, 또는 폐기 상태를 표시한다.
- 현재 수량이 0인 소진 재고와 폐기 완료 재고는 기본 상세 목록에서 제외한다.
- 소진 및 폐기 완료 재고는 별도의 상태 필터 또는 변동 내역을 통해 조회할 수 있다.
- 상세 조회 화면의 수량과 상태는 데이터베이스 조회 시점의 값을 기준으로 표시한다.
- 상세 조회 이후 입고, 출고, 폐기 또는 환경 검토 처리로 수량과 상태가 변경될 수 있다.



## 처리 결과

- 선택한 의약품과 저장소의 기본 정보가 표시된다.
- 해당 저장소에 보관된 선택 의약품의 개별 재고 목록이 조회된다.
- 각 재고에 대해 다음 정보가 표시된다.
  - 보관 구역
  - 제조번호
  - 실제 유통기한
  - 현재 수량
  - 재고 상태
  - 환경 검토 정보
- 동일한 의약품이라도 보관 구역, 제조번호 또는 실제 유통기한이 다르면 별도의 재고 행으로 표시된다.
- 환경 검토 대상 재고에는 검토 상태와 이상 항목이 함께 표시된다.
- 사용자는 상세 정보를 통해 출고 가능한 재고와 검토 또는 처리해야 하는 재고를 구분할 수 있다.



## 예외 처리

| 예외 조건                               | 처리                                                     |
| ----------------------------------- | ------------------------------------------------------ |
| 로그인하지 않은 사용자가 상세 조회를 요청함            | 로그인 필요 메시지를 표시하고 조회 요청을 거부한다.                          |
| 사용자가 조직에 소속되어 있지 않거나 소속 상태가 유효하지 않음 | 의약품 재고 상세 조회 기능에 대한 접근을 제한한다.                          |
| 재고 조회 권한이 없는 사용자가 상세 조회를 요청함        | 권한이 없다는 메시지를 표시하고 조회 요청을 거부한다.                         |
| 조회 대상 의약품 정보가 전달되지 않음               | 조회 대상을 확인할 수 없음을 안내하고 전체 재고 목록으로 이동시킨다.                |
| 조회 대상 저장소 정보가 전달되지 않음               | 조회 대상을 확인할 수 없음을 안내하고 전체 재고 목록으로 이동시킨다.                |
| 선택한 의약품이 존재하지 않음                    | `의약품 정보를 찾을 수 없습니다.` 메시지를 표시한다.                        |
| 선택한 저장소가 현재 조직에 속하지 않음              | 상세 조회 요청을 거부하고 접근 권한이 없음을 안내한다.                        |
| 선택한 저장소가 삭제되었거나 존재하지 않음             | `저장소 정보를 찾을 수 없습니다.` 메시지를 표시한다.                        |
| 선택한 의약품과 저장소에 해당하는 재고가 없음           | `조회할 재고 정보가 없습니다.` 메시지를 표시한다.                          |
| 재고에 연결된 보관 구역 정보를 찾을 수 없음           | 해당 재고를 비정상 데이터로 기록하고 보관 구역을 `정보 없음`으로 표시하거나 목록에서 제외한다. |
| 재고의 제조번호 또는 실제 유통기한 정보가 없음          | 해당 항목을 `정보 없음`으로 표시하고 비정상 데이터를 기록한다.                   |
| 환경 검토 정보가 존재하지 않음                   | 오류로 처리하지 않고 환경 검토 상태를 `해당 없음`으로 표시한다.                  |
| 환경 검토 정보 조회에 실패함                    | 기본 재고 정보는 표시하고 환경 검토 정보를 조회할 수 없음을 안내한다.               |
| 재고 상세 정보 조회 중 데이터베이스 오류가 발생함        | 조회를 중단하고 `재고 상세 정보를 조회하는 중 오류가 발생했습니다.` 메시지를 표시한다.     |
