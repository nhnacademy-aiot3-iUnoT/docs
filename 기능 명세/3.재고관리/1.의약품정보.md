# 📝 1.1 의약품 정보 저장 

## 기능 목적

> 외부에서 수집한 의약품 기본 정보를 시스템 내부 데이터베이스에 의약품 마스터 정보로 저장한다.
> 동일한 의약품이 중복 저장되는 것을 방지하고, 기존 의약품 정보가 변경된 경우 최신 정보로 갱신하여 입고 등록 및 의약품 검색에 사용할 수 있는 기준 정보를 제공한다.



## 사용자 및 권한

- 시스템이 수집한 의약품 정보를 자동으로 저장한다.
- 시스템 관리자는 필요한 경우 의약품 정보 저장 또는 갱신 작업을 실행할 수 있다.
- 일반 조직 사용자는 의약품 마스터 정보를 직접 수정할 수 없다.
- 일반 조직 사용자는 의약품 마스터 정보를 직접 등록할 수 있다.
- 저장된 의약품 마스터 정보는 모든 조직이 공통으로 사용한다.


## 사전 조건

- 저장 대상 의약품 데이터가 시스템에 전달되어 있어야 한다
- 의약품 정보를 저장할 데이터베이스와 의약품 마스터 테이블이 생성되어 있어야 한다.
- 동일한 의약품을 판단하기 위한 품목기준코드가 제공되어야 한다.



## 입력값

| 항목        | 형식             | 필수 여부 | 설명                    |
|-----------| -------------- | :---: | --------------------- |
| 품목기준코드    | String         |   필수  | 의약품을 식별하는 고유 업무 코드    |
| 제품명       | String         |   필수  | 의약품의 허가된 제품명          |
| 업체명       | String         |   필수  | 의약품 제조 또는 판매 업체명      |
| 저장방법      | String         |   선택  | 의약품의 보관 방법에 대한 원문 정보  |
| 유효기간      | String         |   선택  | 제조일을 기준으로 허가된 사용 가능 기간 |
| 포장단위      | String         |   선택  | 의약품의 포장 수량 및 단위 정보    |
| 성분 및 함량   | String         |   선택  | 의약품의 성분명과 함량에 대한 원문 정보|
| 보관 시 주의사항 | String | 선택 | 의약품 보관 시 주의사항| 
| 마약류 구분    | String 또는 Enum |   선택  | 마약류 해당 여부 또는 마약류 종류   |



## 처리 절차

1. 전달 받은 의약품 정보를 내부 저장 형식으로 변환한다.
2. 품목기준코드, 제품명 및 업체명의 존재 여부를 검증한다.
3. 문자열 항목의 앞뒤 공백을 제거한다.
4. 품목기준코드를 기준으로 동일한 의약품이 존재하는지 조회한다.
5. 동일한 품목기준코드가 존재하지 않으면 신규 의약품 정보를 생성한다.
6. 시스템은 신규 의약품에 내부 의약품 ID를 발급한다.
7. 품목기준코드, 제품명, 업체명, 저장방법, 유효기간, 포장단위, 성분 및 함량 마약류 구분을 저장한다.
8. 선택 항목이 제공되지 않은 경우 해당 항목은 null로 저장한다.
9. 시스템은 신규 의약품 정보의 생성 일시를 기록한다.
10. 저장이 완료되면 처리 결과를 반환한다.


## 업무 규칙

- 의약품 정보는 시스템 내부 의약품 마스터 데이터로 저장한다.
- 의약품은 시스템에서 생성한 내부 의약품 ID를 기본 식별자로 사용한다.
- 품목기준코드는 동일한 의약품 여부를 판단하는 업무상 고유값으로 사용한다.
- 동일한 품목기준코드를 가진 의약품 정보는 중복 저장할 수 없다.
- 품목기준코드, 제품명 및 업체명은 필수 항목이며, 하나라도 누락된 경우 저장하지 않는다.
- 저장방법, 유효기간, 포장단위, 성분 및 함량, 마약류 구분은 값이 없어도 의약품 정보를 저장할 수 있으며, 제공되지 않은 항목은 null로 저장한다.
- 문자열 항목은 앞뒤 공백을 제거한 후 저장한다.
- 저장방법, 유효기간, 포장단위, 성분 및 함량은 임의로 분리하거나 해석하지 않고 전달받은 원문을 저장한다.
- 마약류 구분은 전달받은 값을 기준으로 저장하며 값이 없는 경우 일반 의약품으로 임의 판단하지 않는다.
- 제품명과 업체명은 동일하거나 유사한 값이 존재할 수 있으므로 중복 판단 기준으로 사용하지 않는다.
- 신규 의약품 정보 저장 시 생성 일시는 서버 시간을 기준으로 기록한다.
- 의약품 데이터가 필수값 누락 또는 형식 오류로 검증에 실패한 경우 해당 의약품만 저장 대상에서 제외한다.
- 의약품 정보를 저장하는 과정에서 데이터베이스 오류가 발생한 경우 해당 의약품이 포함된 저장 단위의 처리를 롤백한다.
- 저장에 실패한 데이터 또는 저장 단위는 실패 사유를 기록하고 재처리 대상으로 관리한다.




## 처리 결과

- 검증을 통과한 의약품 정보가 의약품 마스터에 저장된다.
- 저장된 의약품에는 시스템 내부 의약품 ID가 부여된다.
- 품목기준코드, 제품명, 업체명, 저장방법, 유효기간, 포장단위, 성분 및 함량, 마약류 구분이 저장된다.
- 저장방법, 유효기간, 포장단위, 성분 및 함량, 마약류 구분이 제공되지 않은 경우 해당 항목은 null로 저장된다.
- 신규 의약품 정보의 생성 일시가 서버 시간을 기준으로 기록된다.
- 검증에 실패한 의약품 정보는 저장되지 않고 제외 대상으로 처리된다.
- 저장 단위의 데이터베이스 처리에 실패한 경우 해당 저장 단위는 롤백되고 재처리 대상으로 관리된다.



## 예외 처리

| 예외 조건                         | 처리                                                  |
| ----------------------------- | --------------------------------------------------- |
| 품목기준코드가 누락됨                   | 해당 의약품 정보를 저장하지 않고 필수값 누락으로 기록한다.                   |
| 제품명이 누락됨                      | 해당 의약품 정보를 저장하지 않고 필수값 누락으로 기록한다.                   |
| 업체명이 누락됨                      | 해당 의약품 정보를 저장하지 않고 필수값 누락으로 기록한다.                   |
| 품목기준코드, 제품명 또는 업체명이 공백으로만 구성됨 | 공백 제거 후 값이 없으면 해당 의약품 정보를 저장하지 않는다.                 |
| 선택 항목이 누락됨                    | 오류로 처리하지 않고 해당 항목을 `null`로 저장한다.                    |
| 입력값의 길이가 저장 가능한 범위를 초과함       | 해당 의약품을 저장 대상에서 제외하고 초과한 항목을 기록한다.                  |
| 입력값을 내부 저장 형식으로 변환할 수 없음      | 원문 저장이 가능한 항목은 원문으로 저장하고, 저장할 수 없는 경우 해당 의약품을 제외한다. |
| 동일한 품목기준코드가 이미 존재함            | 신규 의약품으로 저장하지 않고 중복 데이터로 처리한다.                      |
| 의약품 정보 저장 중 데이터베이스 오류가 발생함    | 해당 의약품이 포함된 저장 단위의 처리를 롤백하고 실패 사유를 기록한다.            |
| 저장 단위 처리에 실패함                 | 설정된 정책에 따라 재시도하고, 최종 실패 시 재처리 대상으로 기록한다.            |
| 시스템 내부 오류가 발생함                | 현재 저장 단위의 처리를 중단하고 롤백한 후 오류 내용을 기록한다.               |

# 📝 1.2 의약품 정보 조회

## 기능 목적

> 내부 데이터베이스에 저장된 의약품 정보를 제품명 또는 품목기준코드로 검색하고 상세 정보를 조회할 수 있도록 한다.
> 입고 등록 시 사용자가 의약품 기본 정보를 직접 입력하지 않고 저장된 의약품을 선택하도록 하여 오입력, 표기 방식 불일치 및 동일 의약품의 중복 등록을 방지한다.


## 사용자 및 권한

- 로그인한 `OWNER` 또는 재고관리 권한을 가진 조직 사용자가 이용할 수 있다. 
- 사용자는 의약품 정보를 조회할 수 있지만 의약품 마스터 정보를 직접 수정하거나 삭제할 수 없다.
- 의약품 마스터 정보는 특정 조직에 종속되지 않고 모든 조직이 공통으로 사용한다.


## 사전 조건

- 사용자가 로그인한 상태여야 한다.
- 사용자가 현재 조직에 정상적으로 소속되어 있어야 한다.
- 입고 등록에서 조회하는 경우 사용자에게 재고관리 권한이 있어야 한다.
- 의약품 정보가 내부 의약품 데이터베이스에 저장되어 있어야 한다.
- 내부 의약품 데이터베이스를 정상적으로 조회할 수 있어야 한다.



## 입력값

| 항목     | 형식     |  필수 여부 | 설명                    |
| ------ | ------ | :----: | --------------------- |
| 제품명    | String | 조건부 필수 | 검색할 의약품 제품명의 전체 또는 일부 |
| 품목기준코드 | String | 조건부 필수 | 검색할 의약품의 품목기준코드       |




## 처리 절차

1. 사용자가 입고 등록 화면에서 의약품 검색 조건을 입력하고 검색 버튼을 선택한다.
2. 시스템은 사용자의 로그인 상태와 재고관리 권한을 확인한다.
3. 시스템은 검색 조건의 필수 여부와 입력 형식을 검증한다.
4. 시스템은 내부 의약품 데이터베이스에서 검색 조건과 일치하는 의약품을 조회한다.
5. 제품명이 입력된 경우 제품명에 검색어가 포함된 의약품을 조회한다.
6. 시스템은 검색 결과를 반환한다.


## 업무 규칙

- 의약품 검색과 상세 조회는 내부 의약품 데이터베이스를 기준으로 수행한다.
- 제품명은 전체 또는 일부 문자열로 검색할 수 있다.
- 품목기준코드는 정확히 일치하는 방식으로 검색하는 것을 원칙으로 한다.
- 제품명과 품목기준코드를 모두 입력한 경우 두 조건을 모두 만족하는 의약품을 조회한다.
- 검색어는 압뒤 공백을 제거한 후 조회에 사용한다.
- 의약품 선택 및 상세 조회에는 품목기준코드가 아닌 내부 의약품 ID를 사용한다.
- 검색 결과에서 의약품을 선택하는 것만으로 재고가 생성되지 않는다.



## 처리 결과

- 검색 조건과 일치하는 의약품 목록이 화면에 표시된다.
- 검색 결과에는 품목기준코드, 제품명, 업체명 및 저장방법이 표시된다.
- 사용자는 검색 결과에서 입고할 의약품을 선택할 수 있다.
- 선택한 의약품의 품목기준코드, 제품명, 업체명, 저장방법, 유효기간, 포장단위, 성분 및 함량, 마약류 구분이 표시된다.

## 예외 처리

| 예외 조건                   | 처리                                        |
| ----------------------- | ----------------------------------------- |
| 제품명과 품목기준코드를 모두 입력하지 않음 | 제품명 또는 품목기준코드 중 하나를 입력하도록 안내한다.           |
| 제품명과 품목기준코드를 모두 입력함     | 하나의 검색 조건만 입력하도록 안내한다.                    |
| 검색어가 공백으로만 구성됨          | 공백 제거 후 검색 조건이 없는 것으로 처리하고 다시 입력하도록 안내한다. |
| 검색 조건과 일치하는 의약품이 없음     | `검색 조건과 일치하는 의약품이 없습니다.` 메시지를 표시한다.       |
| 내부 데이터베이스 조회 실패         | 조회를 중단하고 오류 메시지를 표시한다.                    |
