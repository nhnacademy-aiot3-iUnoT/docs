# 📝 3.13 재고 저장소 이동

## 기능 목적

> 의약품 재고를 한 저장소에서 다른 저장소로 이동할 때 출고 사유를 이동으로 등록하고, 이동 이력을 체계적으로 관리하기 위한 기능이다.


## 사용자 및 권한

- 해당 조직의 `OWNER`또는 재고관리 권한이 `ACTIVE`된 사용자



## 사전 조건

- 사용자는 해당 조직 내 재고 관리 권한을 부여받은 상태여야 한다.


## 입력값

| 항목         | 형식    | 필수 여부 | 설명      |
|--------------|---------|:---------:|-----------|
| TRANSFER_OUT | ENUM    |     Y     | 출고 사유 |
| quantity     | Integer |     Y     | 이동 수량 |
| remark       | String  |     N     | 비고      |



## 처리 절차

- 이동하려는 의약품의 제품명 또는 품목기준코드를 검색한다.
- 해당 의약품의 출고를 선택하고 수량을 입력한다.
- 재고의 출고 사유를 이동으로 선택한다.
- 권한, 재고 수량 및 의약품 상태를 검증한다.
- 해당 저장소의 재고가 차감되고 출고 내역에 사유를 `이동`으로 기록된다.


## 규칙 및 요구사항

1. - [ ] 한 저장소 안에서의 위치 이동은 관여하지 않는다.
2. - [ ] 같은 부서 안의 저장소일지라도 저장소 단위의 이동은 출고로 판단한다.
3. - [ ] 이동 수량은 1개 이상이어야 한다.
4. - [ ] 소진 또는 검토 중 상태의 재고의 이동은 불가해야 한다.
5. - [ ] 이동 수량 이상의 가용 재고가 존재해야 한다.
6. - [ ] 출발 저장소에서의 내역에 도착 저장소의 위치도 기록되어야 한다.
7. - [ ] 출발 저장소와 도착 저장소는 서로 달라야 한다.
8. - [ ] 출발 저장소와 도착 저장소는 활성 상태여야 한다.
9. - [ ] 사용자는 재고를 이동할 수 있는 권한이 있어야 한다.
10. - [ ] 이동 과정에서 의약품명과 로트번호가 병경되어서는 안 된다.
11. - [ ] 완료된 이동 내역은 직접 수정하거나 삭제하지 않고, 취소 또는 반대 재고 처리로 이력을 관리해야 한다.
12. - [ ] 내역에는 처리자, 처리 시각, 출발.도착 저장소, 의약품, 로트번호, 수량 및 사유가 기록되어야 한다.


## 처리 결과

- 출발 저장소의 해당 의약품·로트 재고가 이동 수량만큼 차감된다.
- 도착 저장소의 동일 의약품·로트 재고가 이동 수량만큼 증가된다.
- 출고 내역에는 출고 사유가 `이동(TRANSFER)`으로 기록된다.

## 예외 처리

| 예외 조건                                  | 처리                                                  |
|--------------------------------------------|-------------------------------------------------------|
| 필수 입력값이 누락됨                       | 처리할 수 없음                                        |
| 재고 관리 권한이 없는 경우                 | 권한 없음 오류를 반환한다.                            |
| 출발·도착 저장소가 같은 경우               | 동일 저장소로 이동할 수 없다는 오류를 반환한다.       |
| 이동 수량이 1 미만인 경우                  | 올바른 수량을 입력하도록 안내한다.                    |
| 이동 수량이 가용 재고를 초과한 경우        | 재고 부족 오류와 현재 가용 재고를 반환한다.           |
| 이동할 수 없는 상태의 재고인 경우          | 해당 재고의 상태와 이동 불가 사유를 반환한다.         |
| 의약품 또는 로트 정보가 존재하지 않는 경우 | 재고 정보를 찾을 수 없다는 오류를 반환한다.           |
| 처리 중 일부 작업이 실패한 경우            | 전체 처리를 롤백하고 이동 실패로 기록한다.            |
| 동시 처리로 재고가 변경된 경우             | 최신 재고를 기준으로 재검증하고 충돌 오류를 반환한다. |
