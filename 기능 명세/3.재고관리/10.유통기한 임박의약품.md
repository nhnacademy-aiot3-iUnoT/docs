# 📝 10.1 유통기한 임박 의약품 데이터 자동 갱신

## 기능 목적

> 전체 재고 데이터 중 유통기한이 14(기준)일 이하로 남은 의약품을 필터링 하여 임박 알림 테이블에 저장

## 사용자 및 권한

- 시스템(재고관리 서비스)

## 사전 조건

- 매일 00:00:00(또는 시스템 부하가 적은 시간대)에 스케쥴러를 통해 갱신 프로세스 가동


## 처리 절차

1. 기존 테이블 전체 데이터 삭제
2. 재고 데이터 전체 조회
3. 현재 날짜보다 14일 이내의 유통기한을 가진 재고의 정보와 함께 남은 유통기한 일수 DB저장

## 입력값

없음

## 업무 규칙

- 유통기한이 설정되있지 않은 의약품은 제외
- 유통기한이 이미 지난 의약품은 남은일수 0으로 통일

## 처리 결과

- 성공 시: 의약품의 남은 유통기한 정보 갱신

## 예외 처리

| 예외 조건         | 처리     |
|---------------|--------|
| 저장 중 DB 장애 발생 | 저장 재시도 |



# 📝 10.2 유통기한 임박 의약품 조회 기능

## 기능 목적

> 사용자가 유통기한이 임박한 의약품의 정보를 확인할 수 있게한다.

## 사용자 및 권한

- 재고 관리 권한을 가진 사용자

## 사전 조건

- 사용자가 유통기한 임박 의약품 웹 페이지로 진입함


## 처리 절차

1. 사용자가 유통기한 임박 의약품 웹 페이지로 진입했을때 조회 요청을 받음
2. 유통기한 임박 의약품 페이징 조회
3. 사용자에게 임박의 약품 DTO리스트를 포함한 ApiResponse반환

## 입력값

| 항목    | 형식      | 필수 여부 | 설명            |
|-------|---------|:-----:|---------------|
| 페이지   | Integer |   Y   | 조회할 페이지       |
| 사이즈   | Integer |   Y   | 페이지당 항목 수     |

## 업무 규칙

- 유통기한 임박 내역이 없을경우 빈리스트 반환

## 처리 결과

- 성공 시: 의약품의 남은 유통기한 정보DTO를 담은 ApiResponse반환
- 실패 시: error ApiResponse반환

## 예외 처리

| 예외 조건             | 처리                            |
|-------------------|-------------------------------|
| 조회 중 DB 장애 발생     | error Api Response 반환         |
