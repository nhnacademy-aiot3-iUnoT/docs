# 📝 3.5 의약품 출고

## 기능 목적

>의약품의 로트번호, 유통기한, 보관 위치, 출고 수량을 기준으로 출고 가능 여부를 검증하고, 출고로 인한 재고 변동과 처리 이력을 기록하여 재고의 정확성과 추적성을 확보하기 위한 기능인다. 

## 사용자 및 권한

- 해당 조직의 `OWNER` 또는 해당 조직 내 재고관리 권한이 부여된 사용자만 처리할 수 있다.
- 출고 취소는 `OWNER` 또는 해당 출고 건 등록자만 수행할 수 있다.
- 마약류/고가 의약품 출고는 별도 권한 또는 승인 절차가 필요하다.


## 사전 조건

- 사용자는 해당 조직 내 재고 관리 권한을 부여받은 상태여야 한다.
- 출고하려는 재고의 상태가 `NORMAL`이어야 한다.


## 입력값

| 항목      | 형식 | 필수 여부 | 설명                       |
|-----------|------|:---------:|----------------------------|
| 로트 번호 |      |     Y     | 출고할 의약품 제조번호     |
| 출고 수량 |      |     Y     | 출고할 의약품 수량         |
| 출고 사유 |      |     Y     | 이동, 폐기, 비고(이동위치) |

## 처리 절차

1. 사용자의 소속 조직 및 재고관리 권한을 확인한다. 
2. 출고 위치, 로트번호, 유통기한, 수량을 확인한다. 
3. 출고 사유를 저장한다.
4. 시스템은 유통기한 만료, 검토 중, 폐기 대기 여부로 출고 가능 재고인지를 확인한다. 
5. 최종 출고 정보를 확인하는 모달을 생성한다. 
6. 출고 위치의 해당 의약품 재고 수량을 차감한다. 
7. 시스템은 안전재고 미달 여부를 확인하고 필요 시 알림을 생성한다. 
8. 시스템은 출고 완료 후 상세내역으로 이동한다.

## 규칙 및 요구사항

1. - [ ] 출고는 의약품, 로트번호, 유통기한, 보관 위치, 수량 단위로 처리한다. 
2. - [ ] 같은 의약품이라도 로트번호 또는 유통기한이 다르면 별도 재고로 구분하여 출고한다.
3. - [x] 출고는 사용, 이동, 반품, 회수, 재고 실사 등 출고 유형별로 구분하여 관리한다.
4. - [x] 출고 유형이 위치 이동인 경우 출고 위치와 도착 위치를 반드시 구분하여 관리한다.
5. - [x] 출고 위치와 도착 위치는 동일할 수 없다.
6. - [ ] 출고 위치에 존재하는 재고만 출고할 수 있으며, 다른 위치의 동일 로트 재고에는 영향을 주지 않는다.
7. - [ ] 출고 시 출고 위치의 재고만 감소한다.
8. - [ ] 출고 가능한 로트 목록은 유통기한이 빠른 순서로 표시한다.
9. - [ ] 출고 수량은 0보다 커야 하며, 소수점 입력을 허용할 수 있다.
10. - [ ] 출고 수량이 현재 재고 수량과 같으면 해당 재고 수량은 0이 된다.
11. - [ ] 재고 수량이 0이 된 경우 해당 재고 상태를 소진 상태로 변경한다.
12. - [ ] 출고 완료 후 재고가 안전재고(최소 재고) 이하가 되면 재고 부족 알림을 생성한다.
13. - [ ] 출고 건은 고유 출고 번호를 가진다.
14. - [ ] 해당 재고가 폐기, 이동 등 후속 처리된 경우 출고 취소를 제한할 수 있다.
15. - [ ] 출고 등록은 권한이 있는 사용자만 사용이 가능하다.
16. - [ ] 특정 부서 사용자는 본인 부서와 관련된 출고만 등록할 수 있다.
17. - [ ] 출고 기준 수량은 의약품명, 로트번호, 위치가 모두 일치하는 재고의 가용 수량을 기준으로 한다.
18. - [ ] 안전재고 기준은 조직 또는 보관 위치별로 사용자가 다르게 설정할 수 있다.
19. - [ ] 동일 약품 + 동일 로트 번호 + 동일 위치에서 동시 처리 시 재고 수량이 꼬이지 않아야 한다.

## 화면 표시 요구사항

1. - [ ] 약품 검색 시 현재 재고 수량을 함꼐 표시한다.
2. - [ ] 출고 수량 입력창에는 현재 출고 가능 수량을 표시한다.
3. - [ ] 로트번호 검색 시 유통기한과 위치별 수량을 표시한다.
4. - [ ] 출고 전 확인 모달을 표시한다.
5. - [ ] 출고 완료 후 잔여 수량을 표시한다.

## 처리 결과

- 의약품 출고가 완료되면 선택한 보관 위치의 해당 로트 재고 수량이 출고 수량만큼 차감된다.
- 출고 완료 후 입출고 내역에서 해당 출고 건이 자동으로 생성된다.
- 처리 이력으로 출고 일시, 처리자, 출고 위치, 사용처, 로트번호, 유통기한, 수량, 출고 사유가 저장된다.
- 출고 내역은 입·출고·폐기 내역 조회 화면에서 확인할 수 있다.
- 출고 후 재고가 안전재고 이하가 되면 재고 부족 알림이 생성된다.
- 출고 처리에 실패한 경우 재고 수량은 변경되지 않는다.


## 예외 처리

| 예외 조건                | 처리                   |
|----------------------|----------------------|
| 출고 권한이 없는 사용자        | 출고를 처리할 수 없다.        |
| 출고 수량이 0이하인 경우       | 출고를 처리할 수 없다.        |
| 필수 입력값이 누락됨          | 출고를 처리할 수 없다.        |
| 현재 재고보다 많은 수량 입력     | 출고를 처리할 수 없다.        |
| 사용 보류/폐기 예정/회수 대상 재고 | 출고를 처리할 수 없다.        |
| 출고 처리 중 오류 발생        | 재고 차감 및 이력 생성을 거부한다. |
