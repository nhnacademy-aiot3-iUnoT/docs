# 📝 3.6 의약품 폐기

## 기능 목적

>사용 불가하거나 사용이 제한된 의약품을 폐기 처리하여 재고 수량에서 차감하고, 폐기 사유·처리자·처리 일시·대상 로트 정보를 기록함으로써 의약품 재고의 추적성 및 안전한 관리가 목적이다.


## 사용자 및 권한

- 해당 조직의 `OWNER` 또는 해당 조직에서 재고관리 권한이 `ACTIVE`된 사용자만 처리할 수 있다.
- 폐기 취소는 `OWNER` 또는 해당 폐기 건 등록자만 수행할 수 있다.
- 마약류/고가 의약품 폐기는 별도 권한 또는 승인 절차가 필요하다.

고

## 사전 조건

- 사용자는 해당 조직 내 재고 관리 권한을 부여받은 상태여야 한다.
- 폐기 대기 상태의 재고가 존재해야 한다.


## 입력값

| 항목      | 형식 | 필수 여부 | 설명                           |
|---------|----|:-----:|------------------------------|
| 로트 번호   |    |   Y   | 폐기할 의약품 로트 번호                |
| 의약품명/코드 |    |   Y   | 폐기할 의약품명/코드                  |
| 폐기 사유   |    |   Y   | 파손, 유통기한 만료, 보관 환경 이상, 회수 대상 |
| 폐기 위치   |    |   Y   | 폐기 위약품 보관 위치                 |
| 폐기 수량   |    |   Y   | 폐기할 의약품 수량                   |
| 유통기한    |    |   N   | 유통기한 만료 폐기 시                 |
| 비고      |    |   N   | 폐기 사유에서 기타 선택 시              |


## 처리 절차

1. 시스템은 사용자의 조직 및 재고 관리 권한을 확인한다. 
2. 폐기할 로트번호, 유통기한, 보관 위치을 확인한다.
3. 폐기 수량이 해당 재고의 현재 수량 이하인지 확인합니다. 
4. 사용자가 입력한 폐기 사유가 누락되지 않았는지 검증합니다. 
5. 폐기 확인 모달을 생성합니다. 
6. 폐기 해당 재고의 상태값을 폐기 완료( `DISPOSED`)로 변경합니다. 
7. 일부 폐기일 경우 [현재 수량 - 폐기 수량]으로 차감 업데이트 합니다. 
8. 의약품 폐기 이력에 실체 폐기 수량, 처리 전후 수량, 폐기 기본정보, 처리 담당자 ID, 처리 일시가 기록됩니다. 
9. 재고 현황 목록을 동기화 합니다.



## 규칙 및 요구사항

1. - [ ] 폐기는 유통기한, 로트번호, 의약품, 보관 위치, 수량 단위로 처리한다.
2. - [ ] 같은 의약품이라도 로트번호 또는 유통기한이 다르면 별도 재고로 구분하여 폐기한다.
3. - [ ] 다른 위치의 동일 로트 재고에는 영향을 주지 않는다.
4. - [ ] 폐기 수량은 0보다 커야 하며, 의약품 관리 단위에 따라 소수점 입력을 허용할 수 있다.
5. - [ ] 폐기 수량이 현재 재고 수량과 같으면 재고 수량은 0이 된다.
6. - [ ] 재고 수량이 0이 된 경우 해당 재고 상태를 소진 또는 폐기완료 상태로 변경한다.
7. - [ ] 폐기 사유는 필수로 입력되어야 한다.
8. - [ ] 비고는 선택 입력으로 관리한다.
9. - [ ] 취소된 폐기 건은 다시 취소할 수 없어야 한다.
10. - [ ] 폐기 건은 고유의 폐기번호를 가진다.
11. - [ ] 폐기 취소 시 기존 폐기 이력은 삭제하지 않는다.
12. - [ ] 폐기 완료 후 해당 재고에 후속 처리 이력이 존재하면 폐기 취소를 제한할 수 있다.
13. - [ ] 폐기 처리에 실패한 경우 재고 수량은 변경되지 않는다.
14. - [ ] 동일 약품 + 동일 로트 번호 + 동일 위치에서 동시 처리 시 재고 수량이 꼬이지 않아야 한다.
15. - [ ] 소수점 수량 허용 여부를 명확히 확인해야 한다.
16. - [ ] 

## 화면 표시 요구사항

1. - [ ] 약품 검색 시 위치별 현재 재고 수량을 함꼐 표시한다.
2. - [ ] 폐기 수량 입력창에는 현재 폐기 가능 수량을 함께 표시한다.
3. - [ ] 폐기 전 확인 모달을 생성한다.
4. - [ ] 폐기 완료 후 잔여 수량을 표시한다.
5. - [ ] 폐기 사유를 선택 목록으로 제공하고, 기타 선택 시 비고 입력을 허용한다.

## 처리 결과

- 폐기가 확정되면 폐기번호가 생성된다.
- 폐기가 확정된 수량만큼 해당 보관 위치의 해당 로트 재고 수량이 차감된다.
- 처리 이력으로 폐기 일시, 처리자, 대상 위치, 로트번호, 수량, 폐기 사유가 저장된다.
- 폐기 내역은 입·출고·폐기 내역 조회 화면에서 확인할 수 있다.



## 예외 처리

| 예외 조건             | 처리         |
|-------------------|------------|
| 권한 없는 사용자         | 처리 할 수 없다. |
| 폐기 수량이 0인 경우      | 처리 할 수 없다. |
| 재고보다 많은 수량 처리 시도  | 처리 할 수 없다. |
| 폐기 위치에 존재하지 않는 재고 | 처리 할 수 없다. |
| 필수값이 입력되지 않음      | 처리 할 수 없다. |
