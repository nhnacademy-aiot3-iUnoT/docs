## 용어

| 용어 | 의미 |
| --- | --- |
| DB `id` | 내부 관계와 저장에만 사용하는 식별자. 외부에 노출하지 않는다. |
| UUID | 외부 계정 식별자이자 JWT Subject. 로그인 정보로 사용하지 않는다. |
| 이메일 (`email`) | 로그인, 알림, 계정 복구에 사용하는 고유 이메일 |
| 인증 코드 | 이메일 소유 확인을 위한 짧은 수명의 일회용 숫자 코드 |
| 재설정 토큰 | 비밀번호 변경에만 사용할 수 있는 짧은 수명의 일회용 토큰 |

## 기능 흐름

| 상황 | 이용 기능 | 완료 결과 |
| --- | --- | --- |
| 회원가입 전 이메일 확인 | 이메일 중복 확인 | 이메일 사용 가능 여부 반환 |
| 신규 사용자 | 회원가입 | `USER`, `ACTIVE` 계정 생성 |
| 비밀번호를 잊음 | 링크 또는 코드 요청 → 새 비밀번호 설정 | 비밀번호 변경, 기존 Refresh Token 폐기 |
| 휴면 계정 사용 | 재활성화 코드 요청 → 코드 확인 | `INACTIVE` → `ACTIVE` |
| 보안상 잠긴 계정 | 관리자 잠금 해제 | `LOCKED` → `ACTIVE` |
| 서비스 탈퇴 | 본인 확인 → 계정 탈퇴 | `WITHDRAWN`, 개인정보 제거 |

## 공통 원칙

- 외부 API는 DB 내부 `id` 대신 UUID를 사용한다.
- 비밀번호, 인증 코드, 재설정 토큰 원문은 저장하거나 로그에 남기지 않는다.
- 비인증 복구 요청에서는 계정 존재 여부와 상태가 드러나지 않게 응답한다.
- 권한 변경, 상태 변경, 개인정보 제거와 같은 중요 작업은 감사 가능한 이력을 남긴다.

## 계정 필드별 제약사항

| 필드 | 형식 | 필수 여부 | 제약사항 |
| --- | --- | :---: | --- |
| `id` | Long | O | DB 내부 식별자. 자동 생성하며 외부 사용자 식별에 사용하지 않는다. |
| `uuid` | UUID | O | 외부 계정 식별자와 JWT Subject. 자동 생성하며 중복·변경할 수 없다. |
| `name` | String | O | 공백 불가, 최대 100자. |
| `email` | String | O | 이메일 형식, 공백 불가, 최대 254자, 중복 불가. |
| `hashedPassword` | String | O | 해시된 비밀번호, 공백 불가, 최대 256자.|
| `accountStatus` | Enum | O | `ACTIVE`, `LOCKED`, `INACTIVE`, `WITHDRAWN`. 신규 계정은 `ACTIVE`이다. |
| `accountRole` | Enum | O | `USER`, `ADMIN`. 신규 계정은 `USER`이다. |
| `createdAt` | DateTime | O | 최초 저장 시 자동 기록하며 이후 변경하지 않는다. |
| `updatedAt` | DateTime | X | 최초 저장 시 자동 기록하고 계정 정보 변경 시 갱신한다. |
| `withdrawnAt` | DateTime | X | 탈퇴 전에는 `null`이며 탈퇴 시 기록한다. |

### 요청 DTO별 입력 제약사항

| DTO | 필드 | 형식 | 필수 여부 | 제약사항 |
| --- | --- | --- | :---: | --- |
| `CreateAccountRequest` | `name` | String | O | 공백 불가, 최대 100자 |
| `CreateAccountRequest` | `email` | String | O | 공백 불가, 유효한 이메일 형식, 최대 254자 |
| `CreateAccountRequest` | `password` | String | O | 공백 불가, 6~64자 |
| `LoginRequest` | `email` | String | O | 공백 불가, 유효한 이메일 형식, 최대 254자 |
| `LoginRequest` | `password` | String | O | 공백 불가, 6~64자 |
| `EmailAvailabilityRequest` | `email` | String | O | 공백 불가, 유효한 이메일 형식, 최대 254자 |
| `UpdateAccountRequest` | `name` | String | X | 입력 시 1~100자 |
| `UpdateAccountRequest` | `password` | String | X | 입력 시 6~64자 |
| `WithdrawAccountRequest` | `password` | String | O | 공백 불가, 6~64자 |
| `PasswordReuseCheckRequest` | `newPassword` | String | O | `@NotBlank`, `@Size(6~64)` 적용 |

> 비밀번호는 요청 DTO에서만 평문으로 전달하며 계정에는 해시한 값만 저장한다.

> `name`, `email`, `hashedPassword`는 정상 계정에서 필수지만 개인정보 제거가 완료된 `WITHDRAWN` 계정에서는 값이 없을 수 있다.
