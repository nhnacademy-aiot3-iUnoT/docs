# 📝 4.2 센서 데이터 검증·저장·조회

## 기능 목적

> `NormalizedSensorProcessingFlow`가 실제·가상 센서의 표준 메시지를 소비하고, 검증과 InfluxDB 저장이 끝날 때까지 RabbitMQ Listener 완료를 연계한다.

## Flow 구성

`NormalizedSensorConsumer` → `SensorPayloadValidationNode` → `DatabaseSaveNode` → `FlowCompletionNode`

이 Flow는 `NormalizedSensorFlowInitializer`가 애플리케이션 초기화 시 인스턴스마다 하나씩 등록·시작한다.

## 처리 절차

1. `NormalizedSensorConsumer`가 `iunot.sensor.normalized.queue`의 JSON을 `SensorPayload`로 역직렬화한다.
2. 메시지에 `FlowProcessingCompletion`을 추가하고 Flow의 출력 포트로 전달한다.
3. `SensorPayloadValidationNode`가 양수 ID, 장치 ID, 센서 타입, 값, 단위와 측정 시각을 검증한다.
4. `DatabaseSaveNode`가 `SensorInfluxService.save()`를 호출한다.
5. `SensorInfluxService`가 지원 센서 타입과 ID를 확인하고 측정 시각을 `Instant`로 변환한다.
6. InfluxDB에 식별값은 Tag, 측정값은 `value` Field로 저장한다.
7. `FlowCompletionNode`가 완료 신호를 전달한다.
8. Consumer는 최대 30초 동안 완료를 기다린 뒤 정상 반환하고 Spring AMQP의 AUTO ACK 처리로 이어진다.

## InfluxDB 저장 구조

| 구분 | 항목 |
| --- | --- |
| Tag | `organization_id`, `storage_id`, `section_id`, `sensor_type`, `device_eui`, `unit` |
| Field | `value` |
| Timestamp | 센서 측정 시각, 누락·오류 시 저장 시점의 현재 시각 |

## 조회 API

| Method | 경로 | 설명 |
| --- | --- | --- |
| GET | `/api/rule-engine/sections/{sectionId}/sensor-data/latest` | 구역의 센서 종류별 최신 데이터 |
| GET | `/api/rule-engine/sections/{sectionId}/sensor-data/history` | 구역의 센서 이력 |
| GET | `/api/rule-engine/storages/{storageId}/sensor-data/latest` | 저장소 내 구역·센서별 최신 데이터 |
| GET | `/api/rule-engine/organizations/{organizationId}/sensor-data/latest` | 조직 내 구역·센서별 최신 데이터 |

이력 조회는 `sensorType`, `from`, `to`, `window`를 선택적으로 사용한다. 기본 조회 기간은 최근 24시간, 기본 집계 주기는 `10m`이며 최신 데이터 조회 범위는 최근 30일이다.

## 완료 기준

- [x] 인스턴스마다 Normalized 처리 Flow가 자동 실행된다.
- [x] 실제·가상 센서가 동일한 Flow에서 검증·저장된다.
- [x] 저장 성공과 Flow 완료가 RabbitMQ Listener에 전달된다.
- [x] 최신 데이터 및 구역 이력 조회 API를 제공한다.
- [x] 내부 MQTT 의존성이 제거되었다.

## 예외 처리

| 예외 조건 | 처리 |
| --- | --- |
| JSON 역직렬화 실패 | 오류를 기록하고 해당 메시지를 종료한다. |
| 센서 데이터 검증 실패 | 완료를 예외 처리하고 재큐잉하지 않는 Reject 예외로 변환한다. |
| Flow 처리 30초 초과 | AMQP 처리 오류를 발생시킨다. |
| 저장 또는 비검증 처리 오류 | 완료를 예외 처리하고 AMQP 처리 오류를 발생시킨다. |
| 조회 조건 오류 | 잘못된 ID·시간 범위·집계 주기 오류를 반환한다. |
