# 📝 4.6 Flow 생명주기 및 룰 설정 관리

## 기능 목적

> 시스템 전역 `ExternalSensorFlow`와 `sectionId`별 `VirtualSensorFlow`, `SectionEnvironmentFlow`의 생명주기를 관리하고, 구역별 룰·가상 센서 설정 변경을 반영한다.

## 사용자 및 권한

- 환경관리 설정 권한을 가진 조직 관리자
- 환경관리 룰엔진 시스템
- 구역 관리 서비스

## 사전 조건

- 구역 정보와 활성 상태를 조회할 수 있어야 한다.
- 룰 설정과 가상 센서 설정을 저장할 수 있어야 한다.
- 외부·내부 MQTT 브로커에 연결할 수 있어야 한다.

## 입력값

| 항목 | 형식 | 필수 여부 | 설명 |
| --- | --- | :---: | --- |
| `organizationId` | Long | O | 조직 식별자 |
| `storageId` | Long | O | 저장소 식별자 |
| `sectionId` | Long | O | 구역별 Flow와 설정 관리 기준 |
| `sectionStatus` | String | O | 활성, 비활성, 삭제 상태 |
| `ruleConfig` | Object | O | 센서별 임계값, 지속 시간, 미수신, 알림 설정 |
| `virtualSensorConfig` | Object | X | 생성 주기, 센서 종류, 값 범위, 발생 확률 설정 |

## 처리 절차

1. 룰엔진 시작 시 `ExternalSensorFlow`를 한 번만 생성하고 시작한다.
2. 활성 구역과 저장된 룰·가상 센서 설정을 조회한다.
3. 활성 구역마다 `SectionEnvironmentFlow-{sectionId}`를 생성하고 시작한다.
4. 가상 센서 설정이 활성화된 구역마다 `VirtualSensorFlow-{sectionId}`를 생성하고 시작한다.
5. 구역이 비활성화되거나 삭제되면 해당 `SectionEnvironmentFlow`와 `VirtualSensorFlow`를 중지하고 제거한다.
6. 룰 또는 가상 센서 설정 변경 요청의 권한과 입력값을 검증한다.
7. 검증된 설정을 저장하고 해당 구역 Flow의 이후 데이터부터 새 설정을 적용한다.
8. Flow 생명주기와 설정 변경 이력을 기록한다.

## 업무 규칙

- `ExternalSensorFlow`는 시스템 전체에 하나만 생성해야 한다.
- 활성 구역마다 같은 `sectionId`의 `SectionEnvironmentFlow`를 하나만 생성해야 한다.
- 가상 센서가 활성화된 구역마다 같은 `sectionId`의 `VirtualSensorFlow`를 하나만 생성해야 한다.
- 구역별 Flow는 다른 구역 Flow와 독립적으로 시작, 중지, 제거할 수 있어야 한다.
- 한 구역이 비활성화되거나 삭제되어도 `ExternalSensorFlow`는 계속 실행해야 한다.
- 서버 재시작 시 활성 구역과 저장된 설정을 기준으로 구역별 Flow를 자동 복구해야 한다.
- 룰 설정 변경을 위해 `SectionEnvironmentFlow`를 재생성하지 않고 실행 중 설정을 갱신해야 한다.
- 가상 센서 설정 변경 시 `VirtualSensorFlow`의 생성 주기와 값 정책을 갱신해야 한다.

## 처리 결과

- [ ] `ExternalSensorFlow`가 중복 없이 실행된다.
- [ ] 활성 구역별 `SectionEnvironmentFlow-{sectionId}`가 생성·실행된다.
- [ ] 가상 센서 활성 구역별 `VirtualSensorFlow-{sectionId}`가 생성·실행된다.
- [ ] 서버 재시작 후 구역별 Flow와 설정이 자동 복구된다.
- [ ] 서비스 중단 없이 변경된 구역별 룰·가상 센서 설정이 적용된다.

## 예외 처리

| 예외 조건 | 처리 |
| --- | --- |
| `ExternalSensorFlow` 중복 생성 요청 | 추가 생성하지 않고 기존 Flow를 유지한다. |
| 동일한 `sectionId`의 Flow 중복 생성 요청 | 추가 생성하지 않고 기존 Flow를 유지한다. |
| 필수 구역 정보 또는 설정 누락 | Flow 생성 또는 설정 변경을 거부하고 오류를 기록한다. |
| 유효하지 않은 임계값·시간·센서 종류 | 설정을 저장하지 않고 검증 오류를 반환한다. |
| 구역별 Flow 시작·중지·제거 실패 | `sectionId`, Flow ID, 실패 원인을 기록한다. |
| 서버 재시작 시 일부 Flow 복구 실패 | 다른 구역 Flow의 복구는 계속하고 실패 대상을 기록한다. |
