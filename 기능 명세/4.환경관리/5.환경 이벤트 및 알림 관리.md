# 📝 4.5 알림 처리

## 기능 목적

> `AlarmNode`가 4.3의 위치별 Flow에서 전달받은 임계값 지속 초과 데이터를 알림 메시지로 변환하고, 메신저 알림 시스템에 전송한다.

## 사용자 및 권한

- 환경관리 룰엔진 시스템
- `AlarmNode`
- 환경 알림 수신 대상으로 등록된 조직 관리자 및 조직원
- 메신저 알림 시스템

## 사전 조건

- 4.3에서 임계값 이탈이 설정된 지속 시간을 초과했어야 한다.
- 알림 활성화 여부와 알림 수신 대상이 설정되어 있어야 한다.

## 입력값

| 항목 | 형식 | 필수 여부 | 설명 |
| --- | --- | :---: | --- |
| 알림 대상 데이터 | Object | O | 4.3에서 전달한 임계값 지속 초과 데이터 |
| 위치·센서·장치 정보 | Object | O | 병원명, `locationId`, 위치명, 센서 종류, 장치 정보 |
| 측정값·임계값·지속 시간 | Object | O | 발생한 측정값, 적용 임계값, 이탈 지속 시간 |
| 발생 시각 | DateTime | O | 임계값 이탈 시작 또는 알림 확정 시각 |
| 알림 설정 | Object | O | 알림 활성화 여부, 수신 대상, 재알림 간격 |

## 처리 절차

1. `AlarmNode`가 알림 대상 데이터를 수신한다.
2. 알림 활성화 여부와 수신 대상을 확인한다.
3. 위치, 센서, 장치, 측정값, 임계값, 지속 시간을 포함한 알림 메시지를 생성한다.
4. 동일한 임계값 이탈 상태의 중복 알림과 재알림 간격을 확인한다.
5. 전송 조건을 충족한 알림 메시지를 메신저 알림 시스템에 전송한다.
6. 알림 전송 결과를 기록한다.

## 업무 규칙

- `AlarmNode`는 4.3에서 전달된 데이터만 처리해야 한다.
- 임계값 이탈 지속 시간이 설정값을 초과한 경우에만 알림을 전송한다.
- 동일한 임계값 이탈 상태에 대한 알림은 중복 전송하지 않아야 한다.
- 재알림이 설정된 경우 지정된 간격이 지난 후에만 추가 알림을 전송한다.
- 알림이 비활성화된 경우 메신저 알림을 전송하지 않는다.

## 처리 결과

- [ ] 임계값 지속 초과 데이터가 알림 메시지로 변환된다.
- [ ] 알림 설정과 중복 전송 정책을 충족한 알림만 메신저 시스템에 전송된다.

## 예외 처리

| 예외 조건 | 처리 |
| --- | --- |
| 알림 대상 데이터 누락 | 알림 메시지를 생성하지 않고 누락 항목을 기록한다. |
| 알림이 비활성화됨 | 메신저 알림을 전송하지 않고 처리 결과를 기록한다. |
| 메신저 알림 전송 실패 | 전송 실패 원인을 기록하고 다른 위치 Flow의 처리는 계속한다. |
