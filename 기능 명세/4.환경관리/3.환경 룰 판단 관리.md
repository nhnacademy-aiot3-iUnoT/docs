# 📝 4.3 위치별 센서 데이터 저장 및 환경 룰 판단

## 기능 목적

> 위치별 `LocationRuleFlow`로 분배된 센서 데이터를 InfluxDB에 저장하고, 센서·장치별 환경 룰을 판단하여 이상 또는 복구 이벤트 생성을 요청한다.

## 사용자 및 권한

- 환경관리 룰엔진 시스템
- 위치별 `LocationRuleFlow`
- InfluxDB
- 환경 이벤트 및 알림 시스템

## 사전 조건

- 대상 위치의 `LocationRuleFlow-{locationId}`가 실행 중이어야 한다.
- InfluxDB와 위치별 환경 룰 설정을 조회할 수 있어야 한다.
- 센서·장치별 마지막 수신 시간과 현재 상태를 저장할 수 있어야 한다.

## 입력값

| 항목 | 형식 | 필수 여부 | 설명 |
| --- | --- | :---: | --- |
| `locationId` | Long | O | 위치 Flow와 룰 적용 기준 |
| `applicationName`, `location` | String | O | InfluxDB에 저장할 병원 또는 캠퍼스명과 위치명 |
| `sensorType` | String | O | `temperature`, `humidity`, `door` 등 표준 센서 종류 |
| `deviceName`, `deviceEui` | String | O | InfluxDB에 저장할 장치 정보와 상태·미수신 관리 기준 |
| `value`, `unit`, `time` | Number, String, String | O | 표준 측정값, 단위, 측정 시각 |
| 환경 룰 설정 | Object | O | 임계값, 이상 지속 시간, 문 열림 허용 시간, 미수신 기준 시간 |

## 처리 절차

1. 위치 Flow는 자신의 `locationId`와 수신 데이터의 `locationId`가 일치하는지 검증한다.
2. 측정 시각을 `Instant`로 변환하고, 변환할 수 없으면 서버 수신 시각을 사용한다.
3. 위치·장치·센서 정보를 Tag으로, 표준 측정값을 Field로 하여 InfluxDB에 저장한다.
4. `locationId + sensorType + deviceEui` 기준으로 마지막 수신 시간을 갱신한다.
5. 활성화된 위치별·센서별 룰을 조회한다.
6. 온도·습도는 임계값과 이상 지속 시간을, 문 센서는 열림 상태와 허용 시간을 검사한다.
7. 이상 상태가 확정되거나 정상으로 복구하면 상태 변화 정보를 4.5 이벤트 처리에 전달한다.
8. 공통 미수신 감시 스케줄러가 마지막 수신 시간을 주기적으로 확인하고, 통신 장애·복구 상태 변화를 생성한다.

## 상태 규칙

```text
NORMAL ──임계값 이탈──▶ PENDING ──지속 시간 충족──▶ ALERT
   ▲                         │                         │
   └──지속 전 정상 복귀─────┘                         │ 정상 복귀
   └──처리 완료─────────────────── RECOVERED ◀──────────┘
```

- `PENDING` 중 정상 범위로 돌아오면 이벤트 없이 `NORMAL`로 전환한다.
- `ALERT` 에서 정상 범위로 돌아오면 `RECOVERED`를 거쳐 복구 이벤트 생성을 요청한 후 `NORMAL`로 전환한다.
- 문 상태는 `UNKNOWN`, `OPEN`, `CLOSED`로 관리하며, 같은 상태가 반복되면 이벤트 생성을 요청하지 않는다.

## 업무 규칙

- 한 위치 Flow는 다른 위치의 저장·룰 판단에 영향을 주지 않아야 한다.
- InfluxDB Tag에는 위치, 센서 종류, 장치, 단위를 저장해야 한다.
- 비활성화된 룰은 판단하지 않아야 한다.
- 동일한 이상, 문 상태, 미수신 상태에 대해 중복 이벤트 생성을 요청하지 않아야 한다.
- InfluxDB 저장 실패 시 룰 판단 진행 여부는 시스템 정책으로 일관되게 관리한다.

## 예외 처리

| 예외 조건 | 처리 |
| --- | --- |
| Flow의 위치 ID와 메시지의 위치 ID가 다름 | 저장·룰 판단을 수행하지 않고 경고 로그를 남긴다. |
| InfluxDB 저장 실패 | 위치, 센서 종류, 장치 정보와 함께 오류 로그를 남긴다. |
| 환경 룰 조회 또는 판단 실패 | 해당 센서의 룰 처리만 중단하고 다른 위치·센서 처리는 계속한다. |
