# 📝 4.1 센서 데이터 수집 및 표준화

## 기능 목적

> 외부 MQTT 메시지를 Raw Queue로 전달하고, 별도 Consumer에서 위치와 센서값을 표준 `SensorPayload`로 변환한다.

## 입력값

| 항목 | 필수 | 설명 |
| --- | :---: | --- |
| `applicationName` | O | 조직 ID 매핑 기준 |
| `location` | O | 저장소 ID 매핑 기준 |
| `point` | O | 구역 ID 매핑 기준 |
| `devEui` | X | 장치 고유 식별자, 누락 시 `unknown` |
| `object` | O | 센서 측정값 Map |
| `time` | X | ISO 8601 측정 시각 |

MQTT 수신 토픽과 서버 수신 시각은 각각 `topic`, `receivedAt`으로 원본 DTO에 함께 저장한다.

## 처리 절차

1. `ExternalSensorFlow`의 `MqttSubscriberNode`가 `application/+/device/+/event/up` 토픽을 QoS 1로 구독한다.
2. MQTT 연결이 끊기면 자동 재연결하고 기존 토픽을 다시 구독한다.
3. 수신 JSON을 `ExternalSensorMessage`로 변환한다.
4. `RabbitRawPublisherNode`가 메시지를 `iunot.sensor.raw.queue`에 발행한다.
5. `RawSensorConsumer`가 메시지를 역직렬화하여 `SensorTransformService`에 전달한다.
6. `SectionCatalog`가 `applicationName + location + point`를 `organizationId`, `storageId`, `sectionId`로 매핑한다.
7. 센서별 `SensorCommand`가 하나의 원본 메시지를 센서 종류별 `SensorPayload`로 분리한다.
8. `NormalizedSensorPublisher`가 각 결과를 `iunot.sensor.normalized.queue`에 발행한다.

## 센서 변환 규칙

| 원본 측정 키 | 표준 센서 타입 | 값 | 단위 |
| --- | --- | --- | --- |
| `temperature` | `temperature` | 숫자 또는 숫자 문자열 | `C` |
| `humidity` | `humidity` | 숫자 또는 숫자 문자열 | `%` |
| `magnet_status` | `door` | `open` → `1.0`, `close` → `0.0` | `bool` |

## 위치 매핑 규칙

- 현재 `SectionCatalog`는 코드에 등록된 임시 Map을 사용한다.
- `applicationName`이나 `location`을 매핑할 수 없으면 메시지를 변환하지 않는다.
- `point`가 비어 있으면 메시지를 변환하지 않는다.
- `point` 값은 존재하지만 등록된 구역을 찾지 못하면 임시 기본 구역인 `sectionId=9`를 사용한다.
- 장소 관리 API를 통한 계층 검증·조회는 아직 구현되지 않았다.

## 완료 기준

- [x] 외부 MQTT 메시지가 Raw Queue에 전달된다.
- [x] 실제 센서 위치가 조직·저장소·구역 ID로 매핑된다.
- [x] 온도·습도·문열림 값이 센서별 `SensorPayload`로 변환된다.
- [x] 한 측정값의 실패가 같은 메시지의 다른 센서값 변환을 중단시키지 않는다.
- [x] 변환 결과가 Normalized Queue에 발행된다.
- [ ] 임시 `SectionCatalog`가 장소 관리 API 연동으로 교체된다.

## 예외 처리

| 예외 조건 | 처리 |
| --- | --- |
| MQTT JSON 파싱 실패 | `rawPayload`만 포함한 메시지로 처리하고 이후 변환 결과는 생성하지 않는다. |
| Raw Queue JSON 역직렬화 실패 | 오류 로그를 남기고 해당 메시지를 종료한다. |
| 위치 매핑 실패 | 경고 로그를 남기고 표준 데이터를 생성하지 않는다. |
| 미지원 측정 키 | 해당 값만 제외한다. |
| 개별 값 변환 실패 | 실패한 값만 제외하고 나머지 값을 계속 변환한다. |
